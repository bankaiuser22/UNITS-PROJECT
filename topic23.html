1. Introduction to JavaScript Objects

An object in JavaScript is a collection of related data and behaviour. It stores information in the form of properties and methods.

Properties contain data, while methods are functions that perform particular tasks.

For example, a student object can store the student's name, roll number and department. It can also contain a method to display student information.

Example:

const student = {
    name: "Asha",
    rollNo: 101,
    department: "Computer Science"
};

console.log(student.name);
console.log(student.rollNo);

Output:

Asha
101

2. Properties of an Object

Properties are the values stored inside an object. Each property has a name and a value.

Example:

const student = {
    name: "Asha",
    age: 20,
    marks: 85
};

In this example:

  • name is a property and Asha is its value.
  • age is a property and 20 is its value.
  • marks is a property and 85 is its value.

Accessing Object Properties

We can access object properties using dot notation or bracket notation.

1. Dot Notation

const student = {
    name: "Asha",
    age: 20
};

console.log(student.name);

Output: Asha

2. Bracket Notation

const student = {
    name: "Asha",
    age: 20
};

console.log(student["age"]);

Output: 20

3. Methods of an Object

A method is a function stored inside an object. It is used to perform an action related to that object.

Example:

const student = {
    name: "Asha",

    displayInfo: function() {
        return "Hello " + this.name;
    }
};

console.log(student.displayInfo());

Output: Hello Asha

Understanding the this Keyword

The this keyword refers to the object that is calling the method. It helps us access the properties of the same object. 

const student = {
    name: "Asha",

    introduce() {
        return "My name is " + this.name;
    }
};

console.log(student.introduce());

Output: My name is Asha

Remember:
Property = Data stored in an object.
Method = Function stored inside an object.

4. Introduction to DOM

DOM stands for Document Object Model. It is a programming interface that represents an HTML document as a tree of objects or nodes.

When a browser loads an HTML page, it creates a DOM tree. JavaScript can use this tree to access and change HTML elements, text, attributes and classes.

The DOM allows JavaScript to make web pages dynamic and interactive without reloading the entire page.

Why is DOM Used?

  • To select HTML elements.
  • To change text inside an element.
  • To change HTML attributes.
  • To add or remove CSS classes.
  • To create new HTML elements.
  • To add new content to a web page.

5. DOM Tree Structure

The DOM represents an HTML document in a tree-like structure. Every part of the document is represented as a node.

The main document contains the HTML element. The HTML element contains the head and body elements. The body can contain headings, paragraphs, buttons and other elements.

Example HTML:


    
        My Page
    

    
        
Hello World

        
Welcome to JavaScript

Simple DOM Tree:

             Document
                 |
               HTML
              /    \
           HEAD    BODY
            |       |
          TITLE    H1
                    |
                    P

The browser creates this structure so JavaScript can access different parts of the HTML document.

Important DOM Terms

  • Document: Represents the complete HTML document.
  • Element: Represents an HTML element such as h1, p or div.
  • Parent: An element that contains another element.
  • Child: An element present inside another element.
  • Node: A part of the DOM tree.

6. Selecting HTML Elements

JavaScript must first select an HTML element before it can read or change that element.

The DOM provides different methods to select elements.

1. getElementById()

This method selects an HTML element using its unique ID.

Syntax:

document.getElementById("idName");

Example:

let heading = document.getElementById("title");

console.log(heading);

2. getElementsByClassName()

This method selects all elements having the given class name. 

document.getElementsByClassName("box");

3. getElementsByTagName()

This method selects all elements having the specified HTML tag name. 

document.getElementsByTagName("p");

4. querySelector()

The querySelector() method selects the first element that matches the given CSS selector. 

document.querySelector("#title");
document.querySelector(".box");
document.querySelector("p");

5. querySelectorAll()

The querySelectorAll() method selects all elements that match the given CSS selector. 

document.querySelectorAll(".box");

Difference Between querySelector() and querySelectorAll()

querySelector():
Selects only the first matching element.

querySelectorAll():
Selects all matching elements.
Important:
# is used for an ID selector.
. is used for a class selector.
The tag name can be used directly.

7. Changing HTML Content Using DOM

JavaScript can change the text displayed inside an HTML element using the textContent property.

What is textContent?

textContent is a DOM property used to read or change the text content of an HTML element.

Syntax:

element.textContent = "New Text";

Example:

let heading = document.getElementById("title");

heading.textContent = "Welcome to JavaScript";

Working Example:

Original Heading

Explanation:

  • First, JavaScript selects the heading using its ID.
  • Then, textContent accesses its text.
  • Finally, the original text is replaced with new text.

8. Changing CSS Classes Using classList

JavaScript can add, remove or toggle CSS classes using the classList property.

This allows us to change the appearance of an HTML element without directly changing its CSS.

Important classList Methods

1. add()

The add() method adds a CSS class to an element. 

element.classList.add("active");

2. remove()

The remove() method removes a CSS class from an element. 

element.classList.remove("active");

3. toggle()

The toggle() method adds a class if it is not present and removes it if it is already present. 

element.classList.toggle("active");

4. contains()

The contains() method checks whether an element has a particular class. 

element.classList.contains("active");

Working Example:

JavaScript DOM Card

Click the button to change my appearance.

Explanation:

When the button is clicked, JavaScript selects the card and toggles the active class. The CSS rules of that class change the card's appearance.

9. Creating and Adding New HTML Elements

JavaScript can create new HTML elements dynamically and add them to an existing web page.

The createElement() method creates a new element. The append() method adds the new element to a parent.

Step 1: Create an Element

let newElement = document.createElement("p");

This creates a new paragraph element.

Step 2: Add Text

newElement.textContent = "This is a new paragraph.";

This adds text inside the paragraph.

Step 3: Add It to the Page

document.body.append(newElement);

This adds the paragraph at the end of the body.

Complete Example:

let newElement = document.createElement("p");

newElement.textContent = "New paragraph added!";

document.body.append(newElement);

Working Example:

Existing paragraph.

Explanation:

  • createElement() creates a new HTML element.
  • textContent adds text inside that element.
  • append() inserts the new element into the selected parent.

10. Common DOM Operations

JavaScript provides several DOM operations to work with HTML elements.

1. Select an Element

const notice = document.querySelector(".notice");

It selects the first element having the notice class.

2. Read or Set Text

element.textContent = "Updated";

It changes the text inside an element.

3. Change a Class

element.classList.toggle("active");

It adds or removes the active class.

4. Create and Add an Element

const newItem = document.createElement("li");

newItem.textContent = "New Item";

list.append(newItem);

It creates a new list item and adds it to the list.

11. Complete JavaScript Object and DOM Example

This example combines a JavaScript object with DOM selection and manipulation. 

const learner = {
    name: "Asha",
    unit: 4,

    introduce() {
        return `${this.name} is studying Unit ${this.unit}.`;
    }
};

const message = document.querySelector("#message");

message.textContent = learner.introduce();

Output:

The message will appear here.

Explanation:

  • First, an object named learner is created.
  • It contains name and unit properties.
  • The introduce() method returns a message.
  • querySelector() selects the HTML element with ID message.
  • textContent displays the returned message on the page.
