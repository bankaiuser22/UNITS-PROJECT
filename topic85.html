08. Regular Expressions in PHP

1. Introduction to Regular Expressions

A Regular Expression (Regex) is a pattern used to search, match, and replace text. It helps programmers find specific patterns inside strings.

PHP uses PCRE (Perl Compatible Regular Expressions) through its preg_* functions.

2. Uses of Regular Expressions

  • Finding a particular pattern in text.
  • Checking whether text matches a pattern.
  • Extracting matching text.
  • Replacing matched text.
  • Checking common input formats.

3. preg_match() Function

The preg_match() function checks whether a string matches a regular expression pattern.

It returns:

  • 1 – If a match is found.
  • 0 – If no match is found.
  • false – If an error occurs.
<?php
$text = "Hello PHP";

$pattern = "/PHP/";

$result = preg_match($pattern, $text);

if ($result === 1) {
    echo "Pattern found";
} elseif ($result === 0) {
    echo "Pattern not found";
} else {
    echo "An error occurred";
}
?>

4. preg_replace() Function

The preg_replace() function searches for text matching a regular expression and replaces it with another value. 

<?php
$text = "Hello 123 World";

$result = preg_replace("/[0-9]+/", "", $text);

if ($result !== null) {
    echo $result;
}
?>

5. Regular Expression Delimiters

Regular expression patterns are written between delimiters. PHP commonly uses forward slashes (/). 

<?php
$text = "Hello PHP";

$pattern = "/PHP/";

echo preg_match($pattern, $text);
?>

6. Case-Insensitive Matching

The i modifier makes a pattern case-insensitive. It matches uppercase and lowercase letters. 

<?php
$text = "hello php";

$pattern = "/PHP/i";

if (preg_match($pattern, $text) === 1) {
    echo "Match found";
} else {
    echo "No match";
}
?>

7. Important Regex Symbols

  • ^ – Matches the beginning of a string.
  • $ – Matches the end of a string.
  • + – Matches one or more occurrences.
  • * – Matches zero or more occurrences.
  • . – Matches a character.
  • \. – Matches a literal dot.
  • \D – Matches any non-digit character.
  • [A-Z] – Matches uppercase letters from A to Z.
  • [0-9] – Matches digits from 0 to 9.

8. Email Pattern Example

A regular expression can check whether text has a common email-like format. 

<?php
$email = "learner@example.edu";

$pattern = '/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i';

$result = preg_match($pattern, $email);

if ($result === 1) {
    echo "Email-like format found";
} elseif ($result === 0) {
    echo "Invalid email-like format";
} else {
    echo "Pattern error";
}
?>

9. Removing Non-Digit Characters

The preg_replace() function can remove characters that are not digits using the \D pattern. 

<?php
$phone = "(555) 123-4567";

$digits = preg_replace('/\D+/', '', $phone);

if ($digits !== null) {
    echo "Digits only: " . $digits;
}
?>

10. Understanding an Email Regex Pattern

Consider the following pattern: 

/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i
  • / / – Delimiters of the pattern.
  • ^ – Beginning of the string.
  • [A-Z0-9._%+-]+ – One or more allowed characters.
  • @ – Matches the @ symbol.
  • [A-Z0-9.-]+ – Matches domain characters.
  • \. – Matches a literal dot.
  • [A-Z]{2,} – Matches at least two letters.
  • $ – End of the string.
  • i – Makes matching case-insensitive.

11. Difference Between preg_match() and preg_replace()

preg_match() preg_replace()
Checks for a pattern. Replaces matching text.
Returns 1, 0 or false. Returns modified text or null.
Used for matching. Used for replacing.

12. Important Note About Email Validation

A regular expression can check a common email format, but it cannot prove that an email address exists or is deliverable.

PHP also provides filter_var() with FILTER_VALIDATE_EMAIL for basic email validation. 

<?php
$email = "learner@example.edu";

if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    echo "Valid email format";
} else {
    echo "Invalid email format";
}
?>

13. Important Points

  • Regex describes patterns in text.
  • PHP uses PCRE for regular expressions.
  • preg_match() is used to find a pattern.
  • preg_replace() is used to replace a pattern.
  • Regex can help check common input formats.
  • Input validation and output encoding are still important.

14. Conclusion

Regular expressions are useful for searching, matching and replacing text. PHP provides preg_match() and preg_replace() functions to perform these operations. They make text processing easier when working with patterns.
