07. String Processing in PHP

1. Introduction to Strings

A string is a sequence of characters used to store text. PHP provides different built-in functions to work with strings. These functions help us inspect, trim, search, replace and format text.

2. Creating Strings in PHP

Strings can be created using single or double quotation marks. Double-quoted strings can directly display variable values. 

<?php
$name = "Amit";
$city = 'Vadodara';

echo $name;
echo $city;
?>

3. trim() Function

The trim() function removes extra whitespace from the beginning and end of a string. 

<?php
$text = "   Hello PHP   ";

$result = trim($text);

echo $result;
?>

4. strlen() Function

The strlen() function returns the length of a string in bytes. It is commonly used to count characters in basic English text. 

<?php
$name = "Programming";

echo strlen($name);
?>

5. mb_strlen() Function

The mb_strlen() function counts characters in a string and is useful for Unicode text. It requires the mbstring extension to be enabled. 

<?php
$text = "Hello World";

echo mb_strlen($text);
?>

6. str_replace() Function

The str_replace() function replaces specific text with another text inside a string. 

<?php
$text = "I like Java";

$result = str_replace("Java", "PHP", $text);

echo $result;
?>

7. strtoupper() Function

The strtoupper() function converts all lowercase English letters in a string into uppercase letters. 

<?php
$text = "hello php";

echo strtoupper($text);
?>

8. strtolower() Function

The strtolower() function converts uppercase English letters into lowercase letters. 

<?php
$text = "HELLO PHP";

echo strtolower($text);
?>

9. substr() Function

The substr() function is used to extract a part of a string. It accepts the string, starting position and optional length. 

<?php
$text = "Hello Programming";

$result = substr($text, 0, 5);

echo $result;
?>

10. strpos() Function

The strpos() function finds the position of the first occurrence of a particular text inside another string. It returns false if the text is not found. 

<?php
$text = "Welcome to PHP";

$position = strpos($text, "PHP");

if ($position !== false) {
    echo "Text found at position " . $position;
} else {
    echo "Text not found";
}
?>

11. String Concatenation

String concatenation means joining two or more strings together. PHP uses the dot (.) operator to join strings. 

<?php
$first = "Hello";
$second = "World";

$result = $first . " " . $second;

echo $result;
?>

12. Complete String Processing Example

This example uses different string functions to process and modify text. 

<?php
$raw = "      Contact: learner@example.edu      ";

$clean = trim($raw);

$normalized = str_replace(
    "Contact:",
    "Email:",
    $clean
);

echo $normalized . PHP_EOL;

$text = "Hello PHP";

echo strtoupper($text) . PHP_EOL;
echo strtolower($text) . PHP_EOL;
echo strlen($text) . PHP_EOL;
echo substr($text, 0, 5) . PHP_EOL;
?>

13. Common String Functions

  • trim() – Removes whitespace from the ends.
  • strlen() – Returns the string length in bytes.
  • mb_strlen() – Counts Unicode characters.
  • str_replace() – Replaces text in a string.
  • strtoupper() – Converts text to uppercase.
  • strtolower() – Converts text to lowercase.
  • substr() – Extracts part of a string.
  • strpos() – Finds the position of text.

14. Conclusion

String processing is an important feature of PHP. It allows programmers to manipulate and manage text using built-in functions. Functions such as trim(), strlen() and str_replace() make string operations easier and faster.
