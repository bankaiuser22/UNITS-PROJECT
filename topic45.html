04. PHP Arrays and Output

1. Introduction to Arrays

An array is a special variable used to store multiple values in a single variable. Instead of creating separate variables, we can store related values together in an array.

2. Types of PHP Arrays

PHP mainly supports three types of arrays:

  • Indexed Array
  • Associative Array
  • Multidimensional Array

3. Indexed Array

An indexed array stores values using numeric indexes. The index of an array normally starts from zero. 

<?php
$subjects = ["PHP", "HTML", "CSS", "JavaScript"];

echo $subjects[0];
echo $subjects[1];
echo $subjects[2];
echo $subjects[3];
?>

4. Creating an Indexed Array

We can create an indexed array using the array() function or square brackets []. 

<?php
$fruits = array("Apple", "Mango", "Banana");

echo $fruits[0];
echo $fruits[1];
echo $fruits[2];
?>

5. Associative Array

An associative array stores values using named keys instead of numeric indexes. Each key is connected with a particular value. 

<?php
$marks = [
    "Amit" => 85,
    "Rahul" => 90,
    "Neha" => 88
];

echo $marks["Amit"];
echo $marks["Rahul"];
echo $marks["Neha"];
?>

6. Multidimensional Array

A multidimensional array is an array that contains one or more arrays inside it. It is useful for storing data in rows and columns. 

<?php
$students = [
    ["Amit", 85],
    ["Rahul", 90],
    ["Neha", 88]
];

echo $students[0][0];
echo $students[0][1];

echo $students[1][0];
echo $students[1][1];
?>

7. Displaying Output Using echo

The echo statement is used to display text, variables and values on the screen. It can output multiple strings. 

<?php
$name = "Amit";
$age = 20;

echo "Student Name: ";
echo $name;
echo "Age: ";
echo $age;
?>

8. Displaying Output Using print

The print statement is also used to display output. It returns the value 1 after execution. 

<?php
$name = "Rahul";

print "Welcome ";
print $name;
?>

9. Using foreach with Arrays

The foreach loop is used to access each element of an array one by one. It works with indexed and associative arrays. 

<?php
$subjects = ["PHP", "HTML", "CSS"];

foreach ($subjects as $subject) {
    echo $subject . "<br>";
}
?>

10. Example of Indexed and Associative Arrays

<?php
$topics = ["Variables", "Arrays", "Loops"];

$marks = [
    "Amit" => 88,
    "Dev" => 76
];

foreach ($topics as $index => $topic) {
    echo ($index + 1) . ". " . $topic . "<br>";
}

foreach ($marks as $name => $score) {
    echo $name . " scored " . $score . "<br>";
}
?>

11. Advantages of Arrays

  • Stores multiple values in one variable.
  • Reduces the need for many separate variables.
  • Makes data easier to manage.
  • Works easily with loops.
  • Helps organize related information.

12. Conclusion

Arrays are useful in PHP for storing and managing multiple values. Indexed arrays use numeric indexes, while associative arrays use named keys. The echo and print statements are used to display output, and foreach helps access array elements.
