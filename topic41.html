HTML Links and Hyperlinks

1. Introduction to HTML Links

HTML links are used to connect one webpage to another webpage or external website. They are also called hyperlinks.

HTML links are defined using the <a> tag.

Basic Syntax:

<a href="URL">Link Text</a>

Example:

<a href="https://www.itmbu.ac.in">
Visit ITM University
</a>

Visit ITM University

2. The href Attribute

The href attribute specifies the destination address of a hyperlink.

Example:

<a href="https://www.google.com">
Google
</a>

Google

3. The target Attribute

The target attribute specifies where to open the linked document.

Types of target Attribute:

  • _self : Opens the link in the same tab.
  • _blank : Opens the link in a new tab.
  • _parent : Opens the link in the parent frame.
  • _top : Opens the link in the full body of the window.

Example:

<a href="https://www.google.com"
   target="_blank">
Visit Google
</a>

Visit Google in New Tab

4. Absolute URLs

An absolute URL uses a complete web address to point to an external website or resource.

Example:

<a href="https://www.google.com">
Google
</a>

Google

5. Relative URLs

A relative URL points to a page or folder within the current website. It does not contain the complete website address.

Example:

<a href="html_images.asp">
HTML Images
</a>

This link points to a page in the current website.

6. Default Link States

HTML links have different default styles:

  • Unvisited Link: Blue and underlined.
  • Visited Link: Purple and underlined.
  • Active Link: Red and underlined.

7. Image as a Link

To use an image as a link, place the <img> tag inside the <a> tag.

Example:

<a href="https://www.google.com">
    <img src="image.jpg"
         alt="Sample Image"
         width="100"
         height="100">
</a>

The image becomes clickable and opens the destination when clicked.

8. Link to an Email Address

The mailto: value is used inside the href attribute to create an email link.

Example:

<a href="mailto:someone@example.com">
Send Email
</a>

Send Email

9. Link Titles

The title attribute provides extra information about a link. It is usually shown as a tooltip when the mouse moves over the link.

Example:

<a href="https://www.itmbu.ac.in"
   title="Visit ITM University">
Visit Website
</a>

Visit Website

Conclusion

HTML links help users navigate between webpages and websites. The <a> tag and href attribute are used to create hyperlinks.
