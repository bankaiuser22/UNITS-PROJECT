05. PHP Conditions, Loops and Functions

1. Introduction

Conditions, loops and functions are important concepts in PHP programming. Conditions are used to make decisions, loops are used to repeat statements, and functions are used to organize reusable blocks of code.

2. PHP Conditional Statements

Conditional statements are used to execute different blocks of code depending on whether a condition is true or false.

3. If Statement

The if statement executes a block of code only when the given condition is true. 

<?php
$age = 20;

if ($age >= 18) {
    echo "You are eligible to vote.";
}
?>

4. If-Else Statement

The if-else statement executes one block when the condition is true and another block when the condition is false. 

<?php
$marks = 35;

if ($marks >= 40) {
    echo "Pass";
} else {
    echo "Fail";
}
?>

5. If-Elseif-Else Statement

This statement is used when we need to check multiple conditions one by one. 

<?php
$marks = 85;

if ($marks >= 90) {
    echo "Grade A";
} elseif ($marks >= 75) {
    echo "Grade B";
} elseif ($marks >= 40) {
    echo "Grade C";
} else {
    echo "Fail";
}
?>

6. PHP Loops

A loop is used to execute a block of code repeatedly. Loops help reduce repeated statements and make programs easier to manage.

7. Foreach Loop

The foreach loop is used to access each element of an array one by one. It is useful for working with indexed and associative arrays. 

<?php
$subjects = ["PHP", "HTML", "CSS"];

foreach ($subjects as $subject) {
    echo $subject . "<br>";
}
?>

8. Foreach Loop with Index

The foreach loop can also access the index and value of each array element. 

<?php
$topics = ["Variables", "Arrays", "Functions"];

foreach ($topics as $index => $topic) {
    echo ($index + 1) . ". " . $topic . "<br>";
}
?>

9. PHP Functions

A function is a reusable block of code that performs a particular task. Functions help avoid writing the same code again and again. 

<?php
function greet() {
    echo "Welcome to PHP Programming!";
}

greet();
?>

10. Functions with Parameters

Parameters are values passed to a function. They allow a function to work with different inputs. 

<?php
function add($a, $b) {
    $sum = $a + $b;
    echo "Sum = " . $sum;
}

add(10, 20);
?>

11. Functions with Return Value

The return statement sends a result back from a function to the place where it was called. 

<?php
function square($number) {
    return $number * $number;
}

$result = square(5);

echo "Square = " . $result;
?>

12. Function with Parameter and Return Type

PHP allows us to specify parameter types and return types. This makes the expected input and output of a function clear. 

<?php
function resultLabel(int $marks): string {
    if ($marks >= 40) {
        return "Pass";
    }

    return "Needs more practice";
}

echo resultLabel(75);
?>

13. Advantages of Functions

  • Functions make code reusable.
  • They reduce code repetition.
  • They make programs easier to understand.
  • They divide large programs into smaller parts.
  • They make program maintenance easier.

14. Conclusion

Conditions help a program make decisions. Loops repeat statements, and functions organize reusable code. These concepts are essential for developing PHP applications.
