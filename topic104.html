Transforming XML Using XSL and XSLT

1. Introduction to XSL

XSL stands for Extensible Stylesheet Language. It is a family of technologies used for working with XML documents.

XSL helps to transform and format XML data into different output formats.

2. Key Parts of XSL

  • XSLT: Rules used for transforming XML documents.
  • XPath: Expressions used for selecting nodes and values from XML documents.
  • XSL-FO: Formatting objects commonly used for paginated output.

3. What is XSLT?

XSLT stands for Extensible Stylesheet Language Transformations.

XSLT is used to transform XML data into HTML, another XML format or plain text.

It reads the source XML tree, selects nodes using XPath and applies template rules to produce the result.

XSLT changes the representation of data. It does not change the original XML document.

4. What is XPath?

XPath is a language used to select elements, attributes and values from an XML document.

Common XPath Expressions

  • / - Selects the document root.
  • catalog/book - Selects book elements inside catalog.
  • @id - Selects the id attribute.
  • title - Selects the title element.
  • price - Selects the price element.

5. How XSLT Works

  1. XSLT reads the source XML document.
  2. XPath selects the required XML nodes.
  3. Template rules are applied to selected nodes.
  4. The transformation produces the result.
  5. The result can be HTML, XML or plain text.

6. Source XML Example

Consider a catalog containing information about two books.

catalog.xml

<catalog>
    <book id="b101">
        <title>Learning XML</title>
        <author>Asha Rao</author>
        <price>450</price>
    </book>

    <book id="b102">
        <title>Data on the Web</title>
        <author>Neil Patel</author>
        <price>525</price>
    </book>
</catalog>

7. XSLT Stylesheet Example

The following XSLT stylesheet selects each book and creates an HTML table.

catalog.xsl

<xsl:stylesheet version="1.0"
xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

    <xsl:output method="html" indent="yes"/>

    <xsl:template match="/">

        <table>
            <tr>
                <th>ID</th>
                <th>Title</th>
                <th>Author</th>
                <th>Price (INR)</th>
            </tr>

            <xsl:for-each select="catalog/book">

                <tr>
                    <td>
                        <xsl:value-of select="@id"/>
                    </td>

                    <td>
                        <xsl:value-of select="title"/>
                    </td>

                    <td>
                        <xsl:value-of select="author"/>
                    </td>

                    <td>
                        <xsl:value-of select="price"/>
                    </td>
                </tr>

            </xsl:for-each>

        </table>

    </xsl:template>

</xsl:stylesheet>

8. Explanation of XSLT Elements

  • xsl:stylesheet: Defines the XSLT stylesheet.
  • xsl:output: Specifies the output format.
  • xsl:template match="/": Begins the template at the document root.
  • xsl:for-each: Selects each book and repeats the enclosed output.
  • xsl:value-of: Reads the value of a selected element or attribute.

9. Connecting XML with XSLT

An XML file can be connected to an XSLT stylesheet using the xml-stylesheet processing instruction.

Example:

<?xml version="1.0" encoding="UTF-8"?>

<?xml-stylesheet type="text/xsl"
href="catalog.xsl"?>

<catalog>
    <book id="b101">
        <title>Learning XML</title>
        <author>Asha Rao</author>
        <price>450</price>
    </book>
</catalog>

Save the XML and XSLT files together. Open the XML file in a browser that supports this stylesheet instruction.

10. Transforming XML using Command Line

XML can also be transformed using the xsltproc command-line utility.

Command:

xsltproc catalog.xsl catalog.xml

The transformed HTML is written to standard output. xsltproc is available with libxslt.

11. Browser Compatibility

The interactive example uses XSLT 1.0 through the browser's XSLTProcessor API.

Some browsers still support this API. However, Chromium warns that XSLT support is deprecated and may be removed.

The xsltproc command is a durable option for local demonstrations.

Conclusion

XSL is a family of technologies used for working with XML. XSLT transforms XML data into HTML, XML or plain text. XPath selects the required nodes and XSLT template rules create the output.
