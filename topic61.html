HTML Lists

1. Unordered HTML List

An unordered list displays items with bullets.

  • Coffee
  • Tea
  • Milk

2. Ordered HTML List

An ordered list displays items with numbers.

  1. Coffee
  2. Tea
  3. Milk

3. HTML Description List

A description list contains terms and their descriptions.

Coffee
- Black hot drink
Milk
- White cold drink

4. Nested HTML List

A list inside another list is called a nested list.

  • Fruits
    • Apple
    • Mango
  • Vegetables
    • Potato
    • Tomato
