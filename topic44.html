XML Syntax Rules

Introduction

XML follows certain syntax rules to create a properly structured document. Every XML document must follow these rules to be well-formed.

1. XML Tags Are Case-Sensitive

XML element names are case-sensitive. This means uppercase and lowercase letters are treated differently.

Example:

Rahul
Rahul

Both Name and name are considered different element names.

2. Every Opening Tag Must Be Closed

Every XML element must have a matching closing tag. If an element is opened, it must be closed properly.

Correct Example:


    Rahul

Incorrect Example:


    Rahul

3. Empty Elements

XML also allows empty elements. An empty element does not contain any text or child elements. It can be written using a self-closing tag.

4. Elements Must Be Properly Nested

XML elements must be closed in the correct order. The inner element must be closed before the outer element is closed.

Correct Example:


    Hello World

Incorrect Example:


    Hello World

5. Attribute Values Must Be Quoted

Attribute values must always be written inside single or double quotation marks.

Correct Example:


    Rahul

Incorrect Example:


    Rahul

6. XML Must Have One Root Element

Every XML document must contain exactly one outermost root element. All other elements must be placed inside it.

Example:


    
        Rahul
    
    
        Amit

7. Special Characters Must Be Escaped

Some special characters have a reserved meaning in XML. They must be written using entity references.

Character Entity Reference
& &amp;
< &lt;
> &gt;

Example:


    XML is easy & useful.

Conclusion

XML syntax rules help create well-formed documents. Proper closing tags, correct nesting, quoted attributes, one root element and escaped special characters are important rules of XML.
