8. CSS Text, Fonts and Borders

1. Introduction

CSS provides different properties to style text, fonts and borders of HTML elements.

Text properties control the appearance and alignment of text. Font properties control the typeface, size and weight of text. Border properties add borders around HTML elements.

2. CSS Typography and Text Properties

Typography means the way text is displayed on a web page. CSS typography properties help make text clear, readable and attractive.

3. Font Family

The font-family property is used to specify the typeface of text.

Syntax:

selector {
    font-family: Arial, sans-serif;
}

Example:

p {
    font-family: Georgia, serif;
}

This text uses the Georgia font family.

We can also provide fallback font families. If the first font is unavailable, the browser can use another available font.

4. Font Size

The font-size property is used to set the size of text. It controls how large or small the text appears.

Syntax:

selector {
    font-size: 20px;
}

Example:

h2 {
    font-size: 30px;
}

p {
    font-size: 18px;
}

This is large text.

This is small text.

The rem unit can also be used for font size. It is relative to the root element's font size.

5. Font Weight

The font-weight property is used to control the thickness or boldness of text.

Common Values:

  • normal
  • bold
  • 100 to 900

Example:

p {
    font-weight: bold;
}

h1 {
    font-weight: 700;
}

This is normal text.

This is bold text.

This is extra bold text.

6. Text Align

The text-align property is used to align text horizontally inside an element.

Common Values:

  • left
  • right
  • center
  • justify

Example:

h1 {
    text-align: center;
}

p {
    text-align: justify;
}

This text is aligned to the left.

This text is aligned to the center.

This text is aligned to the right.

7. Line Height

The line-height property controls the vertical space between lines of text.

Syntax:

selector {
    line-height: 1.6;
}

Example:

p {
    line-height: 1.6;
}
CSS makes long passages easier to read. Line height provides proper vertical spacing between lines of text.

8. Text Decoration

The text-decoration property is used to add decorative lines to text.

Common Values:

  • underline - Adds a line below the text.
  • overline - Adds a line above the text.
  • line-through - Adds a line through the text.
  • none - Removes text decoration.

Example:

p {
    text-decoration: underline;
}

9. Text Transform

The text-transform property is used to change the visual letter case of text without changing the original source text.

Common Values:

  • uppercase - Converts text into capital letters.
  • lowercase - Converts text into small letters.
  • capitalize - Makes the first letter of each word capital.
  • none - Keeps the normal text appearance.

Example:

p {
    text-transform: uppercase;
}

10. CSS Borders

The CSS border property is used to create a border around an HTML element.

A border needs a border style, such as solid or dashed, to become visible.

Border Properties:

  • border-width - Sets the thickness of the border.
  • border-style - Sets the style of the border.
  • border-color - Sets the color of the border.

11. Border Width

The border-width property is used to set the thickness of a border.

Example:

div {
    border-width: 3px;
}

12. Border Style

The border-style property is used to specify the appearance of a border.

Common Border Styles:

  • solid
  • dotted
  • dashed
  • double
  • none

Example:

div {
    border-style: solid;
}

13. Border Color

The border-color property is used to set the color of a border.

Example:

div {
    border-style: solid;
    border-width: 3px;
    border-color: blue;
}

14. Border Shorthand Property

The border shorthand property is used to set border width, style and color in a single declaration.

Syntax:

selector {
    border: width style color;
}

Example:

div {
    border: 3px solid #174f78;
}
This is an example of the border shorthand property.

CSS also allows one to four values to specify the top, right, bottom and left border sides in that order.

Example:

div {
    border-style: solid;
    border-width: 2px 4px 6px 8px;
}

15. Importance of Text, Fonts and Borders

  • Make text easy to read.
  • Control font type, size and weight.
  • Align text properly.
  • Improve the appearance of headings and paragraphs.
  • Create borders around HTML elements.
  • Make web pages more attractive and organized.
Exam Point: CSS text and font properties control the appearance of text. Important properties include font-family, font-size, font-weight, text-align, line-height, text-decoration and text-transform. Border properties include border-width, border-style and border-color.

16. Conclusion

CSS Text, Fonts and Borders are important parts of web designing. They help control the appearance, readability and presentation of content on a web page.
