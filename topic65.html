06. Handling HTML Forms in PHP

1. Introduction to PHP Form Handling

PHP Form Handling is used to collect information entered by users through HTML forms. PHP processes the submitted data on the server and generates a suitable response.

2. What is an HTML Form?

An HTML form is used to collect information from users. It contains input fields, buttons, text areas and other form elements. 

<form method="post">
    <label>Enter Your Name:</label>
    <input type="text" name="name">

    <button type="submit">Submit</button>
</form>

3. GET Method

The GET method sends form data through the URL. The submitted information appears in the address bar. It is generally used for searching and retrieving data. 

<form method="get">
    <label>Enter Your Name:</label>
    <input type="text" name="name">

    <button type="submit">Submit</button>
</form>

4. POST Method

The POST method sends form data in the request body instead of displaying it in the URL. It is commonly used when submitting information to the server. 

<form method="post">
    <label>Enter Your Email:</label>
    <input type="email" name="email">

    <button type="submit">Submit</button>
</form>

5. Difference Between GET and POST

  • GET sends data through the URL.
  • POST sends data in the request body.
  • GET is useful for searching information.
  • POST is commonly used for submitting data.
  • POST does not automatically make data secure.

6. Accessing Form Data Using $_GET

PHP provides the $_GET superglobal array to access information submitted using the GET method. 

<?php
if (isset($_GET["name"])) {
    $name = $_GET["name"];
    echo "Welcome " . htmlspecialchars($name);
}
?>

7. Accessing Form Data Using $_POST

PHP provides the $_POST superglobal array to access information submitted using the POST method. 

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = $_POST["name"] ?? "";

    echo "Welcome " . htmlspecialchars($name);
}
?>

8. Complete PHP Form Example

The following example collects a user's name and displays a welcome message after submission. 

<?php
$name = "";
$message = "";
$error = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {

    $name = trim($_POST["name"] ?? "");

    if ($name === "") {
        $error = "Please enter your name.";
    } elseif (
        preg_match('/\A[^\r\n]{1,60}\z/u', $name) !== 1
    ) {
        $error = "Name must be 60 characters or fewer.";
    } else {
        $message = "Welcome, " . $name . "!";
    }
}

function e(string $value): string {
    return htmlspecialchars(
        $value,
        ENT_QUOTES | ENT_SUBSTITUTE,
        "UTF-8"
    );
}
?>

<!DOCTYPE html>
<html>
<body>

    <h2>Student Greeting Form</h2>

    <form method="post">
        <label>Enter Your Name:</label>
        <input type="text" name="name"
               maxlength="60" required
               value="<?= e($name) ?>">

        <button type="submit">Submit</button>
    </form>

    <p><?= e($message) ?></p>
    <p><?= e($error) ?></p>

</body>
</html>

9. Input Validation

Input validation means checking whether the information entered by a user follows the required rules before processing it.

  • Check whether required fields are empty.
  • Check the length of entered information.
  • Check whether the data follows the expected format.
  • Validate submitted data on the server.

10. Output Escaping

User input should not be displayed directly as HTML. The htmlspecialchars() function converts special characters into safe HTML entities. 

<?php
$name = "<Student>";

echo htmlspecialchars(
    $name,
    ENT_QUOTES | ENT_SUBSTITUTE,
    "UTF-8"
);
?>

11. Important PHP Form Functions

  • $_GET – Reads GET request data.
  • $_POST – Reads POST request data.
  • isset() – Checks whether a variable is set.
  • trim() – Removes extra whitespace at the ends.
  • htmlspecialchars() – Encodes special HTML characters.
  • preg_match() – Checks whether text matches a pattern.

12. Conclusion

PHP form handling allows websites to collect and process user information. GET and POST methods transfer form data to the server. Input validation and output escaping help handle submitted data safely.
