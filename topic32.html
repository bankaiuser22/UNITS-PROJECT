CSS COLORS AND BACKGROUNDS

1. Introduction to CSS Colors

CSS colors are used to change the color of text, backgrounds, borders and other HTML elements. Colors make a webpage attractive and easy to understand.

2. Different Ways to Specify Colors

A. Named Colors

CSS provides predefined color names such as red, blue, green, yellow and black.

This text uses the named color red.

B. HEX Colors

HEX stands for hexadecimal color code. It starts with the # symbol and uses six hexadecimal characters.

This text uses HEX color #0000FF.

C. RGB Colors

RGB stands for Red, Green and Blue. It defines a color using three values. Each value ranges from 0 to 255.

This text uses RGB red color.

D. RGBA Colors

RGBA stands for Red, Green, Blue and Alpha. Alpha controls the transparency of the color. Its value ranges from 0 to 1.

This paragraph uses RGBA background color.

E. HSL Colors

HSL stands for Hue, Saturation and Lightness. It is another method of defining colors in CSS.

This text uses HSL color.

3. CSS Background Properties

CSS background properties are used to set colors and images behind HTML elements.

A. Background Color

The background-color property is used to set a solid background color.

This box has a tomato background color.

B. Background Image

The background-image property is used to set an image as the background of an element.

Background image example.

C. Background Repeat

The background-repeat property controls whether a background image repeats.

repeat - Repeats the image horizontally and vertically.

repeat-x - Repeats the image horizontally.

repeat-y - Repeats the image vertically.

no-repeat - Displays the image only once.

D. Background Position

The background-position property sets the starting position of a background image.

Example: center, top, bottom, left and right.

E. Background Size

The background-size property controls the size of a background image.

cover - Covers the complete background area.

contain - Displays the complete image inside the background area.

F. Background Attachment

The background-attachment property controls whether the background image scrolls with the page or remains fixed.

scroll - Background moves with the page.

fixed - Background remains fixed while scrolling.

4. CSS Linear Gradient

A gradient is a smooth transition between two or more colors. Linear gradient changes colors along a straight direction.
