1. Introduction to Forms and Validation

A form is an HTML element used to collect information from users. It allows users to enter details such as name, email address, password and other information.

Form validation is the process of checking the information entered by a user before accepting or submitting it.

Validation helps ensure that the entered information is correct and follows the required rules.

Examples of Form Validation:

  • Checking whether the name field is empty.
  • Checking whether the email address is valid.
  • Checking whether the password has enough characters.
  • Checking whether the user has selected a required option.
  • Checking whether a number is within the allowed range.

Why is Form Validation Important?

  • It prevents incomplete form submissions.
  • It reduces errors in user information.
  • It guides users to enter correct information.
  • It improves the user experience.
  • It helps reduce unnecessary server requests.
Remember:
Form = Collects information from users.
Validation = Checks whether the entered information is correct.

2. Types of Form Validation

Form validation can be performed using HTML and JavaScript. Both methods help check the information entered by users.

1. HTML Form Validation

HTML provides built-in validation attributes. These attributes allow the browser to check basic input rules without writing JavaScript.

For example, the required attribute makes a field mandatory, while type="email" checks the basic email format.

2. JavaScript Form Validation

JavaScript validation is used when we need additional rules or custom feedback for form fields.

JavaScript can check input values, display messages, highlight errors and decide whether the form should continue with submission.

Example:

function validateForm() {

    let name = document.getElementById("name").value;

    if (name == "") {
        alert("Please enter your name");
        return false;
    }

    return true;
}

Here, JavaScript checks whether the name field is empty. If it is empty, an alert message is displayed.

Difference Between HTML and JavaScript Validation

HTML Validation:
Uses built-in attributes.
Suitable for basic input rules.

JavaScript Validation:
Uses JavaScript conditions and methods.
Suitable for custom validation rules.

5. JavaScript Form Validation

JavaScript form validation is used to check user input using JavaScript code. It allows developers to create custom validation rules and display meaningful error messages.

How JavaScript Validation Works

  1. The user enters information into form fields.
  2. The user clicks the submit button.
  3. JavaScript collects the entered values.
  4. JavaScript checks the values against validation rules.
  5. If the information is incorrect, an error message is displayed.
  6. If the information is valid, the program can continue.

Example: Checking an Empty Name

function validateForm() {

    let name = document.getElementById("name").value;

    if (name == "") {

        alert("Please enter your name");

        return false;
    }

    return true;
}

Explanation:

  • document.getElementById() selects the name field.
  • .value reads the value entered by the user.
  • The if statement checks whether the field is empty.
  • alert() displays an error message.
  • return false prevents the form from continuing.

6. Important JavaScript Validation Methods

The browser provides validation methods and properties that JavaScript can use to check form fields.

1. checkValidity()

The checkValidity() method checks whether an element or form satisfies its validation constraints. It returns true if all constraints pass and false if any constraint fails.

Syntax:

form.checkValidity();

Example:

if (form.checkValidity()) {
    console.log("Form is valid");
} else {
    console.log("Form is invalid");
}

2. reportValidity()

The reportValidity() method checks the form and asks the browser to display its validation feedback when a constraint is not satisfied.

Syntax:

form.reportValidity();

3. validity Property

The validity property provides information about the validation state of an input element. It helps JavaScript identify why a field is invalid.

Example:

let input = document.getElementById("email");

console.log(input.validity.valid);

It returns true if the field satisfies its validation constraints and false otherwise.

4. setCustomValidity()

The setCustomValidity() method is used to set a custom validation error message for an input field.

Syntax:

input.setCustomValidity("Custom error message");

To clear a custom validation error, pass an empty string to this method.

Example:

let input = document.getElementById("name");

input.setCustomValidity("Please enter your name");

This sets a custom error message. The message must be cleared with setCustomValidity("") when the input becomes valid.

Remember these four:
checkValidity() = Checks validity.
reportValidity() = Displays browser validation feedback.
validity = Gives validation state information.
setCustomValidity() = Sets a custom error message.

7. preventDefault() Method

The preventDefault() method prevents the browser's default action for an event.

In form validation, it is commonly used inside a submit event listener to prevent the form from submitting immediately. JavaScript can then check the entered values.

Syntax:

event.preventDefault();

Example:

form.addEventListener("submit", function(event) {

    event.preventDefault();

    console.log("Checking form...");
});

In this example, the default form submission is prevented so JavaScript can perform validation first.

8. Validation Flow

Form validation follows a sequence of steps. These steps help ensure that the entered information is checked before it is accepted.

Steps:

  1. Collect Values: Get the values entered by the user when the form is submitted.
  2. Check Basic Constraints: Check required fields, input types and length limits.
  3. Apply Extra Rules: Check any additional rules required by the application.
  4. Display Feedback: Explain how the user can correct any errors.
  5. Continue Submission: Continue only when the values pass validation, and validate them again on the server.

9. Complete Working Example: Form Validation

The following example uses HTML validation and JavaScript together.

Student Registration Form





JavaScript Code:

const form = document.getElementById("studentForm");

const message = document.getElementById("formMessage");

form.addEventListener("submit", (event) => {

    event.preventDefault();

    if (!form.checkValidity()) {

        form.reportValidity();

        message.textContent =
        "Please correct the highlighted fields.";

        return;
    }

    message.textContent = "Form is ready to submit.";

});

Explanation:

  • First, JavaScript selects the form and message elements.
  • addEventListener() listens for the submit event.
  • preventDefault() prevents the normal page reload.
  • checkValidity() checks the HTML validation rules.
  • reportValidity() displays browser feedback if a field is invalid.
  • If all fields are valid, a confirmation message is displayed.
Note: This example only displays a confirmation message. It does not send student information to a server.

10. Client-Side and Server-Side Validation

Client-side validation takes place in the user's browser before data is sent to the server. Server-side validation takes place on the server after the data is received.

Client-Side Validation

  • Runs in the user's browser.
  • Provides quick feedback.
  • Can use HTML attributes and JavaScript.
  • Helps prevent common input mistakes.

Server-Side Validation

  • Runs on the server.
  • Checks submitted information again.
  • Helps protect application data.
  • Is necessary even when client-side validation exists.
Important for Exams:
Client-side validation improves user experience, but it is not a security boundary. Users can disable JavaScript or send data directly to a server. Therefore, the server must also validate submitted data.

11. Advantages of Form Validation

  • Supports safer application design when combined with server-side validation.
