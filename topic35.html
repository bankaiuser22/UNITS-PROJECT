03. PHP Variables and Data Types

1. Introduction

Variables and data types are important parts of PHP programming. Variables are used to store information, while data types define the type of information stored in a variable.

2. What is a Variable?

A variable is a named container used to store data. In PHP, every variable starts with the dollar ($) symbol. The value of a variable can be changed during program execution. 

<?php
$name = "Amit";
$age = 20;

echo $name;
echo $age;
?>

3. Rules for Declaring Variables

  • A variable must start with the $ symbol.
  • A variable name must start with a letter or underscore.
  • A variable name cannot start with a number.
  • Variable names cannot contain spaces.
  • Variable names are case-sensitive.
<?php
$name = "Rahul";
$age = 21;
$_city = "Vadodara";

echo $name;
echo $age;
echo $_city;
?>

4. PHP Data Types

A data type defines the kind of value that a variable stores. PHP supports different types of data.

5. String Data Type

A string is a sequence of characters. It is written inside single or double quotation marks. 

<?php
$name = "Pankaj";
$city = 'Vadodara';

echo $name;
echo $city;
?>

6. Integer Data Type

An integer is a whole number without a decimal point. It can be positive, negative or zero. 

<?php
$age = 20;
$marks = 85;

echo $age;
echo $marks;
?>

7. Float Data Type

A float is a number that contains a decimal point. It is used to store decimal values. 

<?php
$price = 99.50;
$percentage = 85.75;

echo $price;
echo $percentage;
?>

8. Boolean Data Type

A Boolean data type stores only two values: TRUE or FALSE. It is commonly used in conditions. 

<?php
$isStudent = true;
$isAbsent = false;

var_dump($isStudent);
var_dump($isAbsent);
?>

9. Array Data Type

An array is used to store multiple values in a single variable. PHP supports indexed and associative arrays. 

<?php
$subjects = ["PHP", "HTML", "CSS"];

echo $subjects[0];
echo $subjects[1];
echo $subjects[2];
?>

10. NULL Data Type

NULL represents a variable with no value. It is used when a variable is intentionally empty. 

<?php
$address = NULL;

var_dump($address);
?>

11. Checking Data Types

PHP provides the var_dump() function to display the data type and value of a variable. 

<?php
$name = "Amit";
$age = 20;
$price = 45.50;
$passed = true;

var_dump($name);
var_dump($age);
var_dump($price);
var_dump($passed);
?>

12. Conclusion

Variables are used to store information in PHP programs. Data types help identify the kind of value stored. Understanding variables and data types is important for writing correct PHP programs.
