WHY CSS IS NEEDED

1. Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to style and design HTML web pages. HTML provides the structure of a webpage, whereas CSS controls its appearance.

2. Need of CSS

CSS is needed to make websites attractive, beautiful and user-friendly. Without CSS, a webpage looks simple and contains only basic HTML elements.

3. Advantages of CSS

A. Separation of Content and Design: HTML handles content and CSS handles design.

B. Reusability: One CSS file can be used to design multiple HTML pages.

C. Responsive Design: CSS helps websites adjust to mobile, tablet and desktop screens.

D. Saves Time: A single CSS rule can style many elements at the same time.

E. Easy Maintenance: Changes in one CSS file can update the design of multiple webpages.

4. Ways to Add CSS

1. Inline CSS

This paragraph uses Inline CSS.

2. Internal CSS

Internal CSS is written inside the style tag in the head section.

3. External CSS

External CSS is written in a separate .css file and connected using the link tag.
