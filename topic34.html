XML Key Components

Introduction

An XML document is made up of different components. These components organize information in a structured tree format.

1. XML Declaration

The XML declaration is an optional first line of an XML document. It identifies the XML version and character encoding.

2. Element

An element is a named unit of data in an XML document. It can contain text, attributes, other elements or a combination of these.

Example:

Mira Shah

3. Root Element

The root element is the single outermost element of an XML document. It contains all other elements.

Example:


    Mira Shah
    B.Tech CSE

4. Attribute

An attribute provides additional information about an element. It is written inside the starting tag as a name and value pair.

Attribute values must always be written inside quotation marks.

Example:


    Mira Shah

5. Text Node

A text node is the character data written between the starting tag and its matching ending tag.

Example:

88

In this example, 88 is the text node.

6. Comment

A comment is used to add notes for readers. Comments are not considered part of the document's data content.

Summary of XML Components

Component Purpose
XML Declaration Identifies XML version and encoding.
Element Represents a named unit of data.
Root Element Contains all other elements.
Attribute Provides additional information.
Text Node Contains character data.
Comment Adds notes for readers.

Conclusion

XML components help organize information in a structured way. Declaration, elements, attributes, text nodes and comments are important parts of an XML document.
