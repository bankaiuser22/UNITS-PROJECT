TOPIC 1: CLIENT-SIDE SCRIPTING WITH JAVASCRIPT

1. Introduction to JavaScript

JavaScript is a high-level and dynamic scripting language used to make web pages interactive and responsive. It runs in the web browser and responds to user actions.

JavaScript helps us perform calculations, validate forms, change text, display messages, create animations and update web pages without reloading the complete page.

Example:

When we click a button and a message appears on the screen, JavaScript is responsible for that action.

Why is JavaScript Used?

  • To make web pages interactive.
  • To perform calculations.
  • To validate user input.
  • To display popup messages.
  • To respond to button clicks.
  • To change HTML content dynamically.
  • To communicate with servers and fetch data.

2. Difference Between HTML, CSS and JavaScript

HTML, CSS and JavaScript are the three core technologies used in web development.

  • HTML: Provides the structure of a web page.
  • CSS: Controls the design and appearance.
  • JavaScript: Adds behaviour and interactivity.

Example:

HTML       = Creates a button.
CSS        = Changes the button colour.
JavaScript = Performs an action when clicked.
Remember:
HTML = Structure
CSS = Presentation
JavaScript = Behaviour

3. Basic Building Blocks of JavaScript

JavaScript contains different building blocks that help us write programs and perform different tasks.

1. Values

Values are the data used in a JavaScript program. They can be numbers, text or true/false values. 

let age = 20;
let name = "Asha";
let isStudent = true;

2. Variables

A variable is a named container used to store data. We can use that data later in our program. 

let marks = 80;
const name = "Asha";

3. Operators

Operators are symbols used to perform operations on values and variables. 

let a = 10;
let b = 5;

let sum = a + b;

console.log(sum);

Output: 15

4. Expressions

An expression is a combination of values, variables and operators that produces a result. 

let result = 10 + 20;

Output: 30

5. Control Flow

Control flow decides the order in which instructions are executed in a program. Conditions and loops are used for this purpose.

6. Functions

A function is a reusable block of code that performs a particular task. 

function greet() {
    console.log("Hello Student");
}

greet();

Output: Hello Student

7. Objects and Arrays

An object stores related information using properties. An array stores multiple values in a single variable. 

let subjects = ["HTML", "CSS", "JavaScript"];

let student = {
    name: "Asha",
    marks: 85
};

4. JavaScript Variables

A variable is a container used to store information. The stored value can be used or updated in a program.

JavaScript provides three keywords to declare variables: var, let and const.

1. var

The var keyword is used to declare a variable. It can be reassigned and redeclared in the same scope. 

var age = 20;

age = 21;

console.log(age);

Output: 21

2. let

The let keyword is used when the value of a variable may change during program execution. It can be reassigned but cannot be redeclared in the same block scope. 

let marks = 70;

marks = 90;

console.log(marks);

Output: 90

3. const

The const keyword is used when a variable should not be reassigned after declaration. 

const name = "Asha";

console.log(name);

Output: Asha

Difference Between var, let and const

var   - Can be reassigned and redeclared.
let   - Can be reassigned, not redeclared
        in the same block.
const - Cannot be reassigned or redeclared
        in the same block.
Important: Prefer const when reassignment is not required. Use let when the value needs to change.

5. JavaScript Data Types

A data type describes the type of value stored in a variable. JavaScript is dynamically typed, which means a variable can hold different types of values at different times.

JavaScript data types are mainly divided into two categories:

A. Primitive Data Types

Primitive data types represent simple values. JavaScript has seven primitive data types.

1. String

A string is used to store text. It is written inside single quotes, double quotes or backticks. 

let name = "Asha";

console.log(name);

Output: Asha

2. Number

The number data type stores integer and decimal values. 

let age = 20;
let price = 99.50;

console.log(age);
console.log(price);

Output: 20 and 99.5

3. BigInt

BigInt is used to store very large integer values that cannot be safely represented by the Number type. A number literal uses the letter n at the end. 

let bigNumber = 9007199254740993n;

console.log(bigNumber);

4. Boolean

Boolean represents only two values: true or false. It is commonly used in conditions. 

let isPass = true;

console.log(isPass);

Output: true

5. Undefined

Undefined means a variable has been declared but no value has been assigned to it. 

let result;

console.log(result);

Output: undefined

6. Null

Null represents the intentional absence of a value. It means that a variable has no value assigned. 

let student = null;

console.log(student);

Output: null

7. Symbol

Symbol creates a unique value. It is mainly used as a unique property key in objects. 

let id = Symbol("id");

console.log(id);

B. Non-Primitive Data Type

Object

An object is a collection of related data stored in the form of properties and values. Arrays and functions are also object types in JavaScript. 

let student = {
    name: "Asha",
    age: 20,
    marks: 85
};

console.log(student.name);

Output: Asha

Array Example

An array is used to store multiple values in a single variable. 

let subjects = ["HTML", "CSS", "JavaScript"];

console.log(subjects[0]);

Output: HTML

6. typeof Operator

The typeof operator is used to check the data type of a value or variable.

Example:

let name = "Asha";
let age = 20;
let isPass = true;

console.log(typeof name);
console.log(typeof age);
console.log(typeof isPass);

Output:

string
number
boolean

Important Points About typeof

  • typeof "Hello" returns string.
  • typeof 20 returns number.
  • typeof true returns boolean.
  • typeof undefined returns undefined.
  • typeof null returns object due to a historical JavaScript behaviour.
  • typeof an array returns object.
  • typeof a function returns function.

To check whether a value is an array, use: 

Array.isArray(["HTML", "CSS"]);

Output: true

7. Conditions and Logic

Conditions are used to make decisions in a program. They execute different blocks of code depending on whether a condition is true or false.

1. if Statement

The if statement executes a block of code only when the given condition is true. 

let age = 20;

if (age >= 18) {
    console.log("Eligible");
}

Output: Eligible

2. if-else Statement

The if-else statement executes one block when the condition is true and another block when the condition is false. 

let marks = 35;

if (marks >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}

Output: Fail

3. else-if Statement

The else-if statement is used when we need to check multiple conditions. 

let marks = 75;

if (marks >= 90) {
    console.log("Grade A");
} else if (marks >= 60) {
    console.log("Grade B");
} else {
    console.log("Grade C");
}

Output: Grade B

4. Ternary Operator

The ternary operator is a short way of writing a simple if-else condition. 

let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);

Output: Adult

Logical Operators

Logical operators are used to combine or reverse conditions. 

&&  AND - Both conditions must be true.

||  OR  - At least one condition must be true.

!   NOT - Reverses the result.

Example:

let age = 20;
let feesPaid = true;

if (age >= 18 && feesPaid) {
    console.log("Student can register");
} else if (age >= 18 && !feesPaid) {
    console.log("Please pay the fees");
} else {
    console.log("Student is not eligible");
}

Output: Student can register

8. Loops in JavaScript

Loops are used to execute a block of code repeatedly until a particular condition becomes false. They reduce repetition and make programs shorter.

1. for Loop

A for loop is used when we know how many times we want to repeat a block of code.

Syntax:

for (initialization; condition; update) {
    // Code to execute
}

Example:

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Output:

1
2
3
4
5

2. while Loop

A while loop repeats a block of code as long as the given condition is true.

Syntax:

while (condition) {
    // Code to execute
}

Example:

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

Output:

1
2
3
4
5

3. for...of Loop

The for...of loop is used to access each value of an iterable such as an array.

Example:

let subjects = ["HTML", "CSS", "JavaScript"];

for (let subject of subjects) {
    console.log(subject);
}

Output:

HTML
CSS
JavaScript

Difference Between for and while Loop

for loop:
Used when the number of repetitions is known.

while loop:
Used when repetition depends on a condition.

9. Functions in JavaScript

A function is a reusable block of code that performs a particular task. It helps us avoid writing the same code again and again.

Advantages of Functions

  • Reduces code repetition.
  • Makes code easier to understand.
  • Makes programs easier to maintain.
  • Allows code to be reused whenever needed.

Syntax:

function functionName() {
    // Statements
}

functionName();

Example 1: Simple Function

function greet() {
    console.log("Welcome Student");
}

greet();

Output: Welcome Student

Example 2: Function with Parameters

Parameters are the values received by a function. They are written inside the parentheses. 

function greet(name) {
    console.log("Hello " + name);
}

greet("Asha");

Output: Hello Asha

Example 3: Function with Return Value

The return statement sends a result back from the function to the place where it was called. 

function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);

Output: 30

Example 4: Calculate Total

function calculateTotal(price, quantity) {
    return price * quantity;
}

let bill = calculateTotal(120, 3);

console.log(bill);

Output: 360

10. Popup Boxes in JavaScript

JavaScript provides popup boxes to interact with users through the browser. There are three commonly used popup methods: alert(), confirm() and prompt().

1. alert()

The alert() method displays a message in a popup box. It provides an OK button.

Syntax:

alert("Message");

Example:

alert("Welcome to JavaScript");

2. confirm()

The confirm() method displays a message with OK and Cancel buttons. It returns true if the user clicks OK and false if the user clicks Cancel.

Syntax:

confirm("Do you want to continue?");

Example:

let answer = confirm("Do you want to continue?");

if (answer) {
    console.log("User clicked OK");
} else {
    console.log("User clicked Cancel");
}

3. prompt()

The prompt() method displays a popup box that asks the user to enter some text. It returns the entered text or null if the user cancels.

Syntax:

prompt("Enter your name:");

Example:

let name = prompt("Enter your name:");

console.log("Hello " + name);

Difference Between Popup Boxes

alert():
Displays a message with an OK button.

confirm():
Displays a message with OK and Cancel buttons.

prompt():
Asks the user to enter text.
