XML Namespaces

Introduction

XML allows users to create their own element names. Sometimes two XML documents use the same element names for different purposes.

XML Namespaces are used to avoid naming conflicts when XML documents from different sources are combined.

What is an XML Namespace?

An XML Namespace is a method used to identify elements and attributes uniquely in an XML document.

It helps distinguish elements that have the same name but belong to different vocabularies.

Why are XML Namespaces Used?

  • To prevent naming collisions.
  • To combine XML data from different sources.
  • To identify elements uniquely.
  • To organize XML documents properly.
  • To distinguish elements with similar names.

Namespace Declaration

A namespace is declared using the xmlns attribute. A prefix is connected to a namespace URI.

Syntax:

xmlns:prefix="namespace-URI"

Explanation of Example

In the above example, the course element declares a namespace using the prefix lib.

The xmlns:lib attribute connects the prefix lib to the namespace URI.

The first title element is an ordinary title element. The second lib:title element belongs to the library namespace.

Both elements have the same local name, but they represent different names because one uses a namespace prefix.

Namespace Components

Component Description
xmlns Used to declare a namespace.
Prefix A short name used before an element name.
URI Identifies the namespace vocabulary.

Important Points

  • Namespaces prevent naming conflicts.
  • Namespaces use the xmlns attribute.
  • A prefix is connected to a URI.
  • The URI identifies the vocabulary.
  • The URI does not have to be a working web page.

Conclusion

XML Namespaces help avoid naming collisions when different XML vocabularies are combined. They make XML documents more organized and uniquely identify elements using prefixes and URIs.
