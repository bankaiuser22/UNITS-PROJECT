Difference Between DTD and XSD

1. Introduction

DTD and XSD are used to define the structure and rules of an XML document.

They specify which elements and attributes are allowed in an XML document and help validate the document.

2. What is DTD?

DTD stands for Document Type Definition. It is a compact grammar used to declare elements, attributes, entities and content models of an XML document.

DTD can be embedded inside an XML document or stored in an external .dtd file.

Example of DTD

<!ELEMENT catalog (product+)>
<!ELEMENT product (name, price)>
<!ATTLIST product id ID #REQUIRED>
<!ELEMENT name (#PCDATA)>
<!ELEMENT price (#PCDATA)>

3. What is XSD?

XSD stands for XML Schema Definition. It is an XML-based grammar used to define the structure, data types and constraints of an XML document.

XSD supports built-in data types such as xs:string, xs:decimal and xs:ID.

Example of XSD

<xs:schema xmlns:xs=
"http://www.w3.org/2001/XMLSchema">

    <xs:element name="student"
    type="xs:string"/>

</xs:schema>

4. Difference Between DTD and XSD

Feature DTD XSD
Full Form Document Type Definition XML Schema Definition
Grammar Format Uses specialized DTD syntax. Uses XML document syntax.
Data Types Limited data typing, such as text and ID. Rich built-in and custom data types.
Namespaces Limited support for namespaces. Designed to support XML namespaces.
Validation Validates XML structure using DTD rules. Validates structure, data types and constraints.
File Extension .dtd .xsd
Typical Choice Simple or legacy document formats. When detailed constraints and typed values are important.

5. Important Differences Explained

A. Grammar Format

DTD uses its own specialized syntax, whereas XSD is written using XML syntax.

B. Data Types

DTD has limited data typing. XSD supports different built-in and custom data types such as decimal and date.

C. Namespaces

DTD has limited namespace support, whereas XSD is designed to support XML namespaces.

D. Constraints

XSD provides more detailed rules and constraints for XML elements and attributes.

6. Advantages of DTD

  • It provides a simple way to define XML structure.
  • It can be stored internally or externally.
  • It is useful for simple and legacy formats.

7. Advantages of XSD

  • It supports rich data types.
  • It supports XML namespaces.
  • It provides detailed validation constraints.
  • It supports reusable type definitions.

8. Conclusion

Both DTD and XSD define the structure and rules of XML documents. DTD is useful for simple document formats, while XSD is more expressive and strongly typed. XSD is preferred when detailed constraints and typed values are important.
