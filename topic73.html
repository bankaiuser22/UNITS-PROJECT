TOPIC 7: INTRODUCTION TO JQUERY

1. Introduction to jQuery

jQuery is a JavaScript library that makes it easier to perform common JavaScript tasks. It provides shorter and simpler methods for selecting HTML elements, handling events, updating the DOM, creating effects and performing AJAX.

jQuery was especially useful when different browsers behaved differently. It provided consistent methods for common web development tasks.

Modern browsers now provide many similar features directly through JavaScript. However, jQuery is still found in existing websites and older projects.

Example:

Suppose we want to select a paragraph and change its text when a button is clicked. jQuery allows us to do this using shorter code.

Definition for Exam:
jQuery is a fast and lightweight JavaScript library that simplifies HTML document manipulation, event handling, animations and AJAX operations.

2. Why is jQuery Used?

jQuery is used to make JavaScript programming shorter and easier to understand. It provides simple methods for working with HTML elements and browser events.

Uses of jQuery:

  • Selecting HTML elements.
  • Handling user events such as clicks.
  • Changing text and HTML content.
  • Adding and removing CSS classes.
  • Creating visual effects.
  • Performing AJAX requests.

Advantages of jQuery:

  • Reduces the amount of code required.
  • Uses simple CSS-style selectors.
  • Makes DOM manipulation easier.
  • Provides convenient event handling methods.
  • Supports method chaining.
  • Was useful for handling browser differences.

3. Basic jQuery Syntax

jQuery uses the dollar sign ($) as a short form for the jQuery function. It is used to select elements and perform operations on them.

Syntax:

$(selector).action();

Explanation:

  • $: Represents the jQuery function.
  • selector: Selects the required HTML element.
  • action(): Performs an operation on the selected element.

Example:

$("#message").text("Hello World");

Explanation:

  • #message selects the element having ID message.
  • text() changes its text content.
  • Hello World is the new text.

4. Document Ready Function

Before working with HTML elements, the browser must create the document elements. jQuery provides a ready function that runs the given code when the DOM is ready to be used.

Syntax:

$(function() {

    // jQuery code here

});

Explanation:

  • $() represents the jQuery function.
  • function() contains the code to execute.
  • The code runs when the DOM is ready.

Example:

$(function() {

    $("#message").text("Document is ready");

});

When the DOM becomes ready, the paragraph with ID message displays the given text.

Remember:
$(function() { ... }) is a short jQuery syntax for running code when the DOM is ready.

5. jQuery Selectors

Selectors are used to select HTML elements so that we can perform operations on them. jQuery uses CSS-style selector syntax.

1. ID Selector

The ID selector selects an element using its ID. It uses the # symbol. 

$("#message")

It selects the element having ID message.

2. Class Selector

The class selector selects elements using their class name. It uses the dot (.) symbol. 

$(".notice")

It selects all elements having class notice.

3. Element Selector

The element selector selects HTML elements using their tag name. 

$("p")

It selects all paragraph elements.

Selector Examples:

$("#heading")
$(".box")
$("p")
$("button")

6. jQuery DOM Manipulation

DOM manipulation means changing the content, attributes or appearance of HTML elements. jQuery provides simple methods for these tasks.

1. text() Method

The text() method is used to get or change the text content of an element. 

$("#message").text("Hello World");

It changes the text of the selected element.

2. html() Method

The html() method is used to get or change the HTML content inside an element. 

$("#message").html("Hello World");

It inserts bold HTML content inside the selected element.

3. val() Method

The val() method is used to get or set the value of form elements such as input fields. 

$("#name").val("Rahul");

It sets the input field value to Rahul.

4. attr() Method

The attr() method is used to get or change an HTML attribute. 

$("#myImage").attr("alt", "Sample Image");

It changes the alt attribute of the selected image.

5. css() Method

The css() method is used to get or change CSS properties of selected elements. 

$("#message").css("color", "red");

It changes the text color to red.

6. addClass() Method

The addClass() method adds a CSS class to the selected element. 

$("#message").addClass("active");

7. removeClass() Method

The removeClass() method removes a CSS class from the selected element. 

$("#message").removeClass("active");

8. toggleClass() Method

The toggleClass() method adds a class if it is not present and removes it if it is already present. 

$("#message").toggleClass("active");
Important Methods:
text() = Changes text.
html() = Changes HTML content.
val() = Changes input value.
attr() = Changes an attribute.
css() = Changes CSS properties.
addClass() = Adds a class.
removeClass() = Removes a class.
toggleClass() = Adds or removes a class.

7. jQuery Event Handling

An event is an action performed by a user or something that happens in the browser. Examples include clicking a button, typing in an input field and submitting a form.

jQuery provides methods to handle these events. One commonly used method is on().

Syntax:

$(selector).on("event", function() {

    // Code to execute

});

Example: Click Event

$(function() {

    $("#myButton").on("click", function() {

        $("#message").text("Button Clicked!");

    });

});

Explanation:

  • #myButton selects the button.
  • on() attaches an event handler.
  • click is the event name.
  • function() contains the code to execute.
  • The paragraph text changes after clicking.

Common Events:

  • click - Occurs when an element is clicked.
  • input - Occurs when the input value changes.
  • submit - Occurs when a form is submitted.
  • keydown - Occurs when a key is pressed.

8. Method Chaining in jQuery

Method chaining means using multiple jQuery methods one after another on the same selected elements.

It helps write shorter and cleaner code.

Example:

$("#message")
    .text("Hello World")
    .addClass("active")
    .css("font-size", "20px");

Explanation:

  1. Selects the element having ID message.
  2. Changes its text to Hello World.
  3. Adds the active class.
  4. Changes its font size to 20 pixels.
Remember:
Method chaining allows multiple operations to be written in a single statement.

9. jQuery Effects

jQuery provides methods for showing, hiding and changing the appearance of HTML elements. These methods are called effects.

1. hide()

The hide() method hides the selected element. 

$("#message").hide();

2. show()

The show() method displays a hidden element. 

$("#message").show();

3. toggle()

The toggle() method switches between showing and hiding an element. 

$("#message").toggle();

4. fadeIn()

The fadeIn() method gradually displays a hidden element. 

$("#message").fadeIn();

5. fadeOut()

The fadeOut() method gradually hides an element. 

$("#message").fadeOut();

6. slideUp()

The slideUp() method hides an element with an upward sliding effect. 

$("#message").slideUp();

7. slideDown()

The slideDown() method displays an element with a downward sliding effect. 

$("#message").slideDown();

10. jQuery and AJAX

jQuery also provides methods for making AJAX requests to a server. This allows a web page to request information without loading a completely new document.

jQuery has methods such as $.ajax() for working with asynchronous HTTP requests.

Basic Syntax:

$.ajax({

    url: "/api/data",

    method: "GET",

    success: function(data) {

        console.log(data);

    },

    error: function(error) {

        console.log(error);

    }

});

Explanation:

  • $.ajax() starts an AJAX request.
  • url specifies the server endpoint.
  • method specifies the HTTP method.
  • success runs when the request succeeds.
  • error handles request failures.

The endpoint must exist and return a suitable response for this example to work.

11. Difference Between JavaScript and jQuery

jQuery is built using JavaScript. It provides shorter methods for many common JavaScript operations.

Task JavaScript jQuery
Select Element document.querySelector("#message") $("#message")
Click Event addEventListener("click", handler) on("click", handler)
Change Text textContent = "Hello" text("Hello")
Toggle Class classList.toggle("active") toggleClass("active")

Important Differences:

  • JavaScript is a programming language.
  • jQuery is a library written in JavaScript.
  • JavaScript provides native browser APIs.
  • jQuery provides shorter, chain-based methods.
  • jQuery must be included in a project before its methods can be used.
