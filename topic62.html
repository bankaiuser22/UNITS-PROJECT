6. CSS Colors

1. Introduction to CSS Colors

CSS Colors are used to add colors to HTML elements. They make a website attractive and improve the appearance of text, backgrounds, borders and other elements.

CSS provides different ways to define colors such as color names, HEX, RGB, RGBA and HSL.

2. Color Property

The color property is used to change the color of text inside an HTML element.

Example:

p {
    color: red;
}

This is an example of red colored text.

3. Background Color Property

The background-color property is used to change the background color of an HTML element.

Example:

div {
    background-color: yellow;
}
This box has a yellow background.

4. Different Ways to Apply Colors

A. Color Names

CSS allows us to use predefined color names such as red, blue, green, yellow and black. 

h1 {
    color: blue;
}

p {
    color: green;
}

Green Color Example

B. HEX Color

HEX stands for Hexadecimal. It represents colors using a six-digit code starting with the # symbol.

The first two digits represent Red, the next two represent Green and the last two represent Blue.

Example:

h1 {
    color: #FF0000;
}

p {
    color: #0000FF;
}
HEX Red: #FF0000
HEX Blue: #0000FF

C. RGB Color

RGB stands for Red, Green and Blue. It defines a color using three values. Each value ranges from 0 to 255.

Example:

h1 {
    color: rgb(255, 0, 0);
}

p {
    color: rgb(0, 0, 255);
}
RGB Red
RGB Blue

D. RGBA Color

RGBA stands for Red, Green, Blue and Alpha. It is similar to RGB but includes an extra alpha value.

Alpha controls the transparency of the color. Its value ranges from 0 to 1.

Example:

div {
    background-color: rgba(255, 0, 0, 0.5);
}
RGBA Red with Transparency

E. HSL Color

HSL stands for Hue, Saturation and Lightness. It is another way to define colors in CSS.

  • Hue: Represents the type of color.
  • Saturation: Represents the intensity of color.
  • Lightness: Represents how light or dark the color is.

Example:

h1 {
    color: hsl(9, 100%, 64%);
}
HSL Color Example

5. Difference Between Color Formats

  • Color Name: Uses predefined color names.
  • HEX: Uses hexadecimal codes.
  • RGB: Uses Red, Green and Blue values.
  • RGBA: RGB with an alpha transparency value.
  • HSL: Uses Hue, Saturation and Lightness.

6. Importance of CSS Colors

  • Makes websites attractive.
  • Improves the appearance of web pages.
  • Highlights important information.
  • Helps users understand different sections.
  • Improves readability when proper contrast is used.
Exam Point: CSS supports different color formats such as Named Colors, HEX, RGB, RGBA and HSL. These formats are used to apply colors to text and backgrounds.

7. Conclusion

CSS Colors are an important part of web designing. They help developers change the color of text and backgrounds. Different color formats provide different ways to apply colors to HTML elements.
