10. PHP Frameworks

1. Introduction to PHP Frameworks

A PHP framework is a reusable foundation used to develop web applications. It provides ready-made tools, libraries and project structures that make development easier and faster.

PHP frameworks help developers perform common tasks without writing everything from the beginning.

2. Why Do We Use PHP Frameworks?

  • To organize application code.
  • To handle web requests and routing.
  • To validate user input.
  • To render HTML templates.
  • To access databases.
  • To handle user sessions.
  • To make testing and maintenance easier.

3. Laravel Framework

Laravel is a full-featured PHP framework used for developing modern web applications. It provides expressive routing, Blade templates, ORM, migrations and a broad ecosystem.

Features of Laravel

  • Expressive routing.
  • Blade template engine.
  • Object Relational Mapper (ORM).
  • Database migrations.
  • Integrated development tools.

4. Symfony Framework

Symfony is a modular PHP framework that provides reusable components. It offers flexible configuration and supports long-term project development.

Features of Symfony

  • Modular architecture.
  • Reusable components.
  • Flexible configuration.
  • Supports complex applications.
  • Useful for long-term projects.

5. CodeIgniter Framework

CodeIgniter is a lightweight PHP framework with a relatively small footprint and straightforward setup. It is useful for projects that need a simpler framework with fewer built-in components.

Features of CodeIgniter

  • Lightweight structure.
  • Simple setup.
  • Relatively small footprint.
  • Fewer built-in moving parts.
  • Suitable for simpler projects.

6. Difference Between Laravel, Symfony and CodeIgniter

Laravel Symfony CodeIgniter
Full-featured framework. Modular framework. Lightweight framework.
Expressive routing and Blade. Reusable components. Straightforward setup.
Modern web applications. Large or complex applications. Simpler projects.
Broad ecosystem. Flexible configuration. Fewer built-in components.

7. What is Composer?

Composer is a dependency manager for PHP. It is used to download and manage libraries and packages required by PHP projects.

Composer is used in the Laravel installation process to download project dependencies.

8. Installing a Laravel Project

To create a Laravel project, a working PHP installation and Composer are required. Internet access is also needed to download the project dependencies.

Step 1: Create a new Laravel project.

composer create-project laravel/laravel php-framework-demo

Step 2: Open the project folder.

cd php-framework-demo

Step 3: Start the development server.

php artisan serve

Visit the local URL shown by Artisan. It is usually http://127.0.0.1:8000

9. Laravel Route Example

A route defines how an application responds to a particular URL. The following example creates a route that accepts a name.

Replace the contents of routes/web.php with the following code: 

<?php

use Illuminate\Support\Facades\Route;

Route::get('/hello/{name}', function (string $name) {
    return view('hello', ['name' => $name]);
});

10. Creating a Laravel View

Create a file named hello.blade.php inside: 

resources/views/hello.blade.php

Write the following HTML code:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Framework Greeting</title>
</head>
<body>

    <h1>Hello, {{ $name }}!</h1>

    <p>
        This page is returned through a
        Laravel route and view.
    </p>

</body>
</html>

Blade is Laravel's template engine. Its {{ }} output syntax escapes HTML by default.

11. When Should We Use a Framework?

A framework is useful when an application requires:

  • Routing.
  • Database access.
  • User authentication.
  • Input validation.
  • Ongoing maintenance.

For a very small script or learning exercise, plain PHP may be enough.

12. Security and Maintenance

  • Use the framework's documented security features.
  • Keep dependencies updated.
  • Validate user input properly.
  • Do not assume that using a framework automatically makes insecure code safe.

13. Unit 6 – Quick Revision

  1. PHP executes on the server and sends a response such as HTML to the browser.
  2. PHP variables begin with the dollar ($) symbol.
  3. PHP uses arrays, conditions, loops and functions to perform application tasks.
  4. String functions help process text.
  5. Regular expressions are used for pattern matching.
  6. Input should be validated and output should be escaped appropriately.
  7. MVC stands for Model, View and Controller.
  8. Laravel, Symfony and CodeIgniter are commonly used PHP frameworks.

14. Conclusion

PHP frameworks provide reusable tools and a structured way to develop web applications. Laravel, Symfony and CodeIgniter offer different features according to project requirements. Composer helps manage PHP dependencies, while Laravel routes and views demonstrate how a framework handles web requests and responses.
