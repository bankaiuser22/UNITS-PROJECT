Introduction to Server-Side Scripting

1. Introduction

Server-side scripting is a technique in which scripts are executed on a web server instead of the user's browser.

The server processes the request, performs required operations and sends a response back to the browser.

The response may contain HTML or JSON data which is displayed or processed by the client.

2. What is PHP?

PHP stands for PHP: Hypertext Preprocessor. Originally, PHP stood for Personal Home Page.

PHP is an open-source server-side scripting language widely used for web development.

PHP code can be embedded inside HTML and is executed by the PHP runtime on the server.

3. Features of PHP

  • PHP is an open-source language.
  • It is used for server-side web development.
  • It can be embedded inside HTML.
  • It can connect with databases.
  • It can process form data.
  • It can generate dynamic web pages.

4. Client-Side and Server-Side Scripting

Client-Side Scripting

Client-side scripting runs in the user's web browser. It is mainly used to create interactive web pages.

Server-Side Scripting

Server-side scripting runs on the web server. It processes requests and generates responses.

5. Request and Response Flow

  1. The browser sends an HTTP request to the web server.
  2. The web server passes the request to the PHP interpreter.
  3. The PHP script is executed on the server.
  4. The script may read or update data.
  5. The server generates an HTML or JSON response.
  6. The browser receives and displays the response.

6. Working of PHP

When a browser requests a PHP file, the web server executes the PHP code. The browser receives the generated output, not the original PHP source code.

7. First PHP Script

The following example displays a greeting using PHP.

hello.php

<?php
$name = 'Asha';

$hour = (int) date('G');

$greeting = $hour < 12
    ? 'Good morning'
    : 'Hello';
?>

<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>PHP Greeting</title>
</head>
<body>

    <h1>
        <?= htmlspecialchars(
            $greeting . ', ' . $name,
            ENT_QUOTES,
            'UTF-8'
        ) ?>
    </h1>

    <p>
        This response was generated by PHP.
    </p>

</body>
</html>

8. Explanation of the Example

  • $name stores the user's name.
  • date('G') gets the current hour.
  • $greeting stores the greeting message.
  • PHP generates the HTML response.
  • htmlspecialchars() safely encodes text for HTML.

9. How to Run a PHP File

A PHP file cannot be executed by simply double-clicking it in a browser. It needs a PHP interpreter or a web server.

Using PHP Development Server

php -S localhost:8000

Open the following address in the browser: 

http://localhost:8000/hello.php

Using Command Line

php hello.php

10. Advantages of Server-Side Scripting

  • It can process user requests.
  • It can access databases and files.
  • It can generate dynamic content.
  • It keeps PHP source code on the server.
  • It supports application logic and validation.

Conclusion

Server-side scripting is used to process requests on a web server. PHP is a popular open-source server-side scripting language that creates dynamic web pages and generates responses for web browsers.
