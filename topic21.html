HTML Elements and Attributes

1. HTML Elements

An HTML element is everything from the start tag to the end tag.

Basic Syntax:

<tagname>Content</tagname>

Example:

<h1>My First Heading</h1>
<p>My First Paragraph</p>

In this example:
- <h1> is the start tag.
- My First Heading is the content.
- </h1> is the end tag.

2. Nested HTML Elements

HTML elements can be nested, which means one element can contain another element.

Example:

<html>
    <body>
        <h1>My First Heading</h1>
        <p>My First Paragraph</p>
    </body>
</html>

The elements are placed inside other elements to build the structure of a web page.

3. Empty HTML Elements

HTML elements that have no content and no closing tag are called empty elements.

Example:

<br>

The <br> tag is used to insert a line break. It does not require a closing tag.

4. HTML Attributes

HTML attributes provide additional information about HTML elements.

Attributes can modify the default behavior or styling of an element.

Syntax:

<tagname attribute="value">

Important Rules:

  • Attributes are always written in the start tag.
  • Attributes are not written in the end tag.
  • Attributes usually come in name/value pairs.

5. Common HTML Attributes

1. href Attribute

The href attribute specifies the destination of a hyperlink. 

<a href="https://www.itmbu.ac.in">
Visit ITM University
</a>

2. src Attribute

The src attribute specifies the path or URL of an image. 

<img src="image.jpg" alt="My Image">

3. alt Attribute

The alt attribute provides alternate text for an image if it cannot be displayed. It also helps screen readers. 

<img src="flower.jpg" alt="Beautiful Flower">

4. width and height Attributes

These attributes specify the width and height of an image in pixels. 

<img src="image.jpg"
     width="500"
     height="300">

5. style Attribute

The style attribute is used to add CSS styling directly to an HTML element. 

<p style="color:red;">
This is a red paragraph.
</p>

6. Example of HTML Elements and Attributes

<!DOCTYPE html>
<html>
<body>

    <h1 style="color:blue;">
        Welcome to HTML
    </h1>

    <p>This is my first webpage.</p>

    <a href="https://www.itmbu.ac.in">
        Visit ITM University
    </a>

    <br>

    <img src="image.jpg"
         alt="Sample Image"
         width="200"
         height="150">

</body>
</html>

Conclusion

HTML elements are the building blocks of a web page. Attributes provide additional information and control the properties of HTML elements.
