TOPIC 4: DHTML – HTML, CSS AND JAVASCRIPT TOGETHER

1. Introduction to DHTML

DHTML stands for Dynamic HTML. It is a descriptive term for using HTML, CSS and JavaScript together to make web pages dynamic and interactive.

DHTML allows a web page to respond to user actions and changes without reloading the entire page. It helps developers change the content, appearance and behaviour of a web page while it is open.

DHTML is not a separate programming language, browser feature or software package. It is a combination of three web technologies: HTML, CSS and JavaScript.

Example:

Suppose there is a button on a web page. When the user clicks that button, the background colour of a card changes.

This interaction uses:

  • HTML to create the card and button.
  • CSS to define the normal and highlighted appearance.
  • JavaScript to detect the click and change the card's state.
Remember:
DHTML = HTML + CSS + JavaScript
It makes web pages dynamic and interactive.

2. Main Components of DHTML

DHTML uses three main technologies. Each technology has a different responsibility. They work together to create an interactive web page.

HTML creates elements such as:

  • Images

CSS controls:

  • Colours
  • Backgrounds
  • Fonts and text sizes
  • Spacing
  • Layout
  • Different visual states of elements

In this example, CSS makes the paragraph blue and gives the button a green background.

3. JavaScript – Behaviour and Interaction

JavaScript is used to add behaviour and interaction to a web page. It allows the page to respond to user actions.

JavaScript can:

  • Respond to button clicks.
  • Change text on a web page.
  • Change CSS classes.
  • Show or hide elements.
  • Update the DOM.
  • Perform calculations and validation.

Example:

document.querySelector("button")
.addEventListener("click", function() {

    alert("Button clicked!");

});

In this example, JavaScript detects when the button is clicked and displays an alert message.

Easy Difference:
HTML = What is on the page?
CSS = How does it look?
JavaScript = What happens when we interact with it?

3. How DHTML Works

DHTML works by combining HTML, CSS and JavaScript. The browser processes these technologies and updates the web page when an interaction occurs.

Steps of DHTML Working:

  1. HTML creates the structure: The browser reads the HTML code and creates a DOM tree of elements.
  2. CSS applies the design: The browser applies CSS rules to decide how the elements should look.
  3. JavaScript finds elements: JavaScript selects the required elements and registers event listeners.
  4. User performs an action: For example, the user clicks a button.
  5. DOM gets updated: JavaScript changes the DOM, such as adding or removing a CSS class.
  6. Browser updates the appearance: The browser applies the changed CSS styles and renders the updated result.

Simple Flow:

Important:
A targeted DHTML update can change only the required part of the page without reloading the entire document.

4. Role of DOM in DHTML

DOM stands for Document Object Model. It represents an HTML document as a tree of objects. JavaScript uses the DOM to access and update the elements of a web page.

In DHTML, JavaScript uses the DOM to change content, attributes and CSS classes.

Example:

Hello Student

Explanation:

  • HTML creates a paragraph and a button.
  • JavaScript selects both elements using querySelector().
  • addEventListener() waits for a button click.
  • textContent changes the paragraph text.

Therefore, the DOM helps JavaScript update the web page dynamically.

5. CSS Classes and JavaScript in DHTML

In DHTML, JavaScript can change the appearance of an HTML element by adding or removing CSS classes.

The classList property provides methods to manage CSS classes.

Important Method: classList.toggle()

The toggle() method adds a class if it is not already present. If the class is already present, it removes that class.

Syntax:

element.classList.toggle("class-name");

Example:


    Hello Student

Here, JavaScript toggles the active class whenever the button is clicked. CSS can define a different appearance for the active class.

JavaScript selects the card and button. It listens for a click on the button. When the click happens, it toggles the is-active class on the card.

8. Good Practices in DHTML

Good practices help developers write clean, understandable and maintainable code.

  • Keep the content and structure in HTML.
  • Keep visual design rules in CSS.
  • Keep interaction logic in JavaScript.
  • Use classList to manage CSS classes.
  • Use addEventListener() to handle events.
  • Use semantic HTML elements such as real buttons.
  • Keep the code easy to read and maintain.

A real button is better than using a normal text element as a button because native buttons support keyboard activation.

9. Difference Between Static and Dynamic Web Pages

Static Web Page

A static web page displays fixed content. Its content does not automatically change in response to user interactions.

Dynamic Web Page

A dynamic web page can respond to user actions and update its content or appearance. DHTML is one way to create such interactions.

Difference:

Static Web Page:
- Displays fixed content.
- Limited interaction.
- Content generally stays the same.

Dynamic Web Page:
- Responds to user actions.
- Can update content and appearance.
- Provides interactive features.
