02. Introduction and Basic Syntax of PHP

1. Introduction to PHP

PHP stands for PHP: Hypertext Preprocessor. It is an open-source server-side scripting language mainly used for web development.

PHP code runs on the web server and generates output such as HTML, which is sent to the user's browser.

2. Basic PHP Syntax

PHP code is written between the opening <?php and closing ?> tags. A semicolon (;) is used to end most PHP statements. 

<?php
echo "Hello World!";
?>

3. PHP Variables

A variable is a container used to store information. In PHP, every variable starts with the dollar ($) symbol. Variable names are case-sensitive. 

<?php
$name = "Rahul";
$age = 20;
$marks = 85;

echo $name;
echo $age;
echo $marks;
?>

4. PHP Comments

Comments are used to explain code. They are ignored by the PHP interpreter. 

<?php
// This is a single-line comment

/*
This is a
multi-line comment
*/

echo "PHP Comments";
?>

5. PHP Data Types

Data types define the kind of value stored in a variable. Common PHP data types include:

  • String – Stores text.
  • Integer – Stores whole numbers.
  • Float – Stores decimal numbers.
  • Boolean – Stores true or false.
  • Array – Stores multiple values.
  • NULL – Represents an empty value.
<?php
$name = "Amit";
$age = 21;
$price = 99.50;
$isStudent = true;

echo $name;
echo $age;
echo $price;
echo $isStudent;
?>

6. PHP Output Statements

PHP uses echo and print to display output. Both are commonly used to show text and values. 

<?php
echo "Welcome to PHP";
print "Learning PHP is easy";
?>

7. PHP Strings

A string is a sequence of characters enclosed within single or double quotation marks. Double-quoted strings can display variable values. 

<?php
$name = "Amit";

echo "Hello $name";
echo 'Welcome to PHP';
?>

8. String Concatenation

The dot (.) operator is used to join two or more strings in PHP. 

<?php
$firstName = "Rahul";
$lastName = "Sharma";

$fullName = $firstName . " " . $lastName;

echo $fullName;
?>

9. PHP Case Sensitivity

PHP variable names are case-sensitive. This means $name and $Name are treated as two different variables. 

<?php
$name = "Amit";
$Name = "Rahul";

echo $name;
echo $Name;
?>

10. Important Points

  • PHP is a server-side scripting language.
  • PHP files are saved with the .php extension.
  • PHP code starts with <?php.
  • Variables begin with the $ symbol.
  • A semicolon ends most PHP statements.
  • Comments explain the program code.
  • Echo and print display output.
  • The dot operator joins strings.

Conclusion

PHP is an important language used to create dynamic websites. Its basic syntax, variables, data types, comments and output statements help programmers write PHP programs easily.
