7. CSS Background Properties

1. Introduction

CSS Background Properties are used to set the background of HTML elements. They help us add background colors, images and gradients to web pages.

Background properties improve the appearance of a website and make its design more attractive.

2. Background Color

The background-color property is used to set a solid background color for an HTML element.

Syntax:

selector {
    background-color: color;
}

Example:

div {
    background-color: lightblue;
}
This is an example of background-color.

3. Background Image

The background-image property is used to add an image behind the content of an HTML element.

Syntax:

selector {
    background-image: url("image.jpg");
}

Example:

div {
    background-image: url("background.jpg");
}

The image file should be available at the specified location for it to appear.

4. Background Repeat

The background-repeat property controls how a background image is repeated inside an element.

Types of Background Repeat:

  • repeat: Repeats the image horizontally and vertically.
  • repeat-x: Repeats the image horizontally.
  • repeat-y: Repeats the image vertically.
  • no-repeat: Displays the image only once.

Example:

div {
    background-image: url("image.jpg");
    background-repeat: no-repeat;
}

5. Background Position

The background-position property is used to set the starting position of a background image inside an element.

Common Values:

  • center
  • top
  • bottom
  • left
  • right
  • right top

Example:

div {
    background-image: url("image.jpg");
    background-position: center;
}

In this example, the background image is positioned at the center of the element.

6. Background Size

The background-size property controls the dimensions of a background image.

Important Values:

  • cover: Scales the image to cover the entire element. Some parts may be cropped.
  • contain: Scales the image so the complete image is visible inside the element.
  • auto: Displays the image using its original dimensions where possible.

Example:

div {
    background-image: url("image.jpg");
    background-size: cover;
}

7. Background Attachment

The background-attachment property controls whether the background image scrolls with the page or stays fixed relative to the viewport.

Types:

  • scroll: The background image scrolls with the element's content.
  • fixed: The background image stays fixed relative to the viewport.
  • local: The background image scrolls with the element's scrollable content.

Example:

body {
    background-image: url("image.jpg");
    background-attachment: fixed;
}

8. CSS Gradients

A gradient is a smooth transition between two or more colors. CSS gradients are treated as background images.

A. Linear Gradient

A linear gradient changes colors along a straight line. 

div {
    background-image:
    linear-gradient(red, yellow);
}
Linear Gradient Example

B. Radial Gradient

A radial gradient spreads colors outward from a central point in a circular or elliptical shape. 

div {
    background-image:
    radial-gradient(red, yellow, green);
}
Radial Gradient Example

9. Combined Background Example

We can use multiple background properties together to create an attractive background. 

.banner {
    background-color: #174f78;

    background-image:
    linear-gradient(120deg, #174f78, #31765e);

    background-repeat: no-repeat;

    background-position: center;

    background-size: cover;
}
Combined Background Example

10. Importance of Background Properties

  • Make web pages visually attractive.
  • Apply different background colors.
  • Add images behind content.
  • Control the position and size of images.
  • Create colorful gradients.
  • Improve the overall design of a website.
Exam Point: CSS background properties include background-color, background-image, background-repeat, background-position, background-size and background-attachment. They are used to control the appearance of an element's background.

11. Conclusion

CSS Background Properties help developers control the background of HTML elements. They provide options for colors, images, image positioning, image sizing, repeating and gradients.
