CSS POSITIONING AND CSS3 FEATURES

1. Introduction to CSS Positioning

CSS positioning is used to control the placement of HTML elements on a webpage. It helps to arrange elements at different positions such as top, bottom, left and right.

2. Types of CSS Positioning

A. Static Position

Static is the default position of every HTML element. Elements appear in their normal document flow.

This element has static positioning.

Example: position: static;

B. Relative Position

Relative positioning moves an element from its original position. Its original space remains reserved in the document.

This element has relative positioning.

Example: position: relative;

C. Absolute Position

Absolute positioning places an element relative to its nearest positioned ancestor. It is removed from the normal document flow.

Parent Element
Absolute Element

Example: position: absolute;

D. Fixed Position

Fixed positioning places an element relative to the browser viewport. It stays at the same position even when the page is scrolled.

Example: position: fixed;

E. Sticky Position

Sticky positioning combines relative and fixed positioning. The element behaves normally until it reaches a specified scrolling position.

This is a sticky element.

Example: position: sticky;

3. CSS3 and Modern CSS Features

CSS3 is commonly used as a classroom term for modern CSS features. CSS is developed through different modules such as Colors, Selectors, Grid and Media Queries.

4. Border Radius

The border-radius property is used to create rounded corners of an HTML element.

This box has rounded corners.

Example: border-radius: 15px;

5. Box Shadow

The box-shadow property is used to add shadow effects around an HTML element.

This box has a shadow effect.

Example: box-shadow: 5px 5px 10px gray;

6. CSS Gradient

A gradient is a smooth transition between two or more colors. Linear gradient changes colors along a straight direction.

This box shows a linear gradient.

Example: background-image: linear-gradient(to right, blue, green);

7. Transform Property

The transform property is used to change the appearance or position of an element. It can rotate, scale, move or skew an element.

Example: transform: scale(1.05);

8. Transition Property

The transition property is used to create a smooth change between different CSS property values.

Move your mouse over this box.

Example: transition: 0.5s;

11. CSS Media Queries

Media queries are used to create responsive webpages. They apply different CSS styles according to screen size or device conditions.

Example: @media (max-width: 600px) { body { background-color: lightblue; } }

12. Responsive Web Design

Responsive web design means creating webpages that automatically adjust their layout according to mobile, tablet and desktop screen sizes.

Flexible layouts, CSS Grid, Flexbox and Media Queries help create responsive webpages.
