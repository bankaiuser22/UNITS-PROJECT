10. CSS3, Flexbox, Grid and Responsive Design

1. Introduction

CSS is used to design and style HTML web pages. Modern CSS provides many features that help developers create attractive, flexible and responsive websites.

CSS3 is commonly used as a classroom term for newer CSS features. Modern CSS is developed through individual modules such as Color, Selectors, Grid and Media Queries.

2. What is CSS3?

CSS3 is a commonly used term for modern CSS features that improve the design and layout of web pages.

These features provide better control over colors, backgrounds, layouts, animations and responsive designs.

Important Features:

  • Rounded corners
  • Box shadows
  • Gradients
  • Transforms
  • Transitions
  • Flexbox
  • CSS Grid
  • Media Queries

3. CSS Modules

Modern CSS is developed as a collection of separate modules. Each module handles a particular part of CSS.

Some important CSS modules are:

  • CSS Color
  • CSS Selectors
  • CSS Grid Layout
  • CSS Media Queries
  • CSS Transforms

There is no single all-encompassing CSS3 or CSS4 release. Individual CSS modules continue to evolve on their own timelines.

4. Rounded Corners

The border-radius property is used to create rounded corners of HTML elements.

Syntax:

selector {
    border-radius: 10px;
}

Example:

.box {
    background-color: green;
    border-radius: 15px;
}
This box has rounded corners.

5. Box Shadow

The box-shadow property is used to add shadow effects around an HTML element.

It gives a depth effect and makes elements look more attractive.

Syntax:

selector {
    box-shadow: horizontal vertical blur color;
}

Example:

.box {
    box-shadow: 3px 3px 10px gray;
}
This box has a shadow effect.

6. CSS Gradients

A gradient is a smooth transition between two or more colors.

CSS gradients are generated images and can be used as backgrounds.

Types of Gradients:

A. Linear Gradient

A linear gradient changes colors along a straight line. 

.box {
    background-image:
    linear-gradient(red, yellow);
}

B. Radial Gradient

A radial gradient spreads colors outward from a central point. 

.box {
    background-image:
    radial-gradient(red, yellow, green);
}

7. CSS Transform

The transform property is used to change the position, size, rotation or shape of an element.

Common Transform Functions:

  • translate() - Moves an element.
  • rotate() - Rotates an element.
  • scale() - Changes the size of an element.
  • skew() - Slants an element.

Example:

.box {
    transform: scale(1.1);
}

8. CSS Transition

The transition property is used to make changes in CSS properties happen smoothly over a specified duration.

For example, when a user moves the mouse over a button, its appearance can change smoothly.

Syntax:

selector {
    transition: property duration;
}

Example:

.box {
    transition: transform 0.3s;
}

.box:hover {
    transform: scale(1.1);
}

9. Choosing a Layout Method

CSS provides different methods to arrange content on a web page.

A. Normal Document Flow

Normal document flow is the default way in which HTML elements are arranged on a web page.

Text and block elements generally appear in their normal order without special positioning.

B. Flexbox

Flexbox is a CSS layout method used to arrange items along one main direction, either horizontally or vertically.

It is useful for navigation bars, rows of buttons and arranging items in a single direction.

Important Flexbox Properties:

  • display: flex
  • flex-direction
  • justify-content
  • align-items
  • flex-wrap
  • gap

Flexbox Syntax:

.container {
    display: flex;
    justify-content: space-around;
    align-items: center;
    gap: 10px;
}

10. CSS Grid

CSS Grid is a layout system used to arrange elements in rows and columns.

It is useful when a web page needs a two-dimensional layout, such as a group of cards or a complete page structure.

Important Grid Properties:

  • display: grid
  • grid-template-columns
  • grid-template-rows
  • gap
  • grid-column
  • grid-row

Grid Syntax:

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 14px;
}

11. Difference Between Flexbox and Grid

Flexbox Grid
One-dimensional layout system. Two-dimensional layout system.
Arranges items in a row or column. Arranges items in rows and columns.
Useful for navigation bars and item rows. Useful for card layouts and page structures.

12. Responsive Web Design

Responsive Web Design means creating web pages that adjust their layout according to different screen sizes and devices.

A responsive website can provide a suitable layout on desktop computers, tablets and mobile phones.

Advantages:

  • Works on different screen sizes.
  • Improves the user experience.
  • Reduces the need for separate layouts.
  • Makes content easier to access on mobile devices.

13. CSS Media Queries

Media Queries are used to apply CSS rules only when a particular condition is true.

For example, we can change the layout when the screen width becomes smaller.

Syntax:

@media (max-width: 600px) {
    .container {
        width: 100%;
    }
}

Example:

@media (max-width: 600px) {
    .feature-list {
        grid-template-columns: 1fr;
    }
}

In this example, the CSS rule is applied when the viewport width is 600px or less.

14. Flexible Grid Layout

CSS Grid can use auto-fit and minmax() to create flexible layouts that adjust according to the available space.

Example:

.feature-list {
    display: grid;

    grid-template-columns:
    repeat(auto-fit, minmax(180px, 1fr));

    gap: 14px;
}

15. Reduced Motion

Some users prefer reduced motion on websites. CSS provides the prefers-reduced-motion media query to respect this preference.

Example:

@media (prefers-reduced-motion: reduce) {
    .motion-demo,
    .motion-demo:hover {
        transition: none;
        transform: none;
    }
}

This example removes the transition and transform effects when the user has requested reduced motion.

16. Importance of Modern CSS Features

  • Make websites attractive and modern.
  • Create flexible layouts.
  • Arrange items using Flexbox and Grid.
  • Add shadows and rounded corners.
  • Create smooth visual transitions.
  • Make websites responsive on different devices.
  • Improve website usability and presentation.
Exam Point: Modern CSS features include rounded corners, box shadows, gradients, transforms and transitions. Flexbox is used for one-dimensional layouts, while Grid is used for two-dimensional layouts. Media Queries help create responsive web pages for different screen sizes.

17. Conclusion

Modern CSS provides powerful tools for designing websites. Flexbox and Grid help arrange elements, while Media Queries make websites responsive. These features help developers create flexible, attractive and user-friendly web pages.
