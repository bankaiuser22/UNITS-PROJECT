1. Introduction to HTML & Basic Structure

What is HTML?

HTML stands for Hyper Text Markup Language. It is the standard markup language used for creating web pages.

Main Points of HTML:

  • Standard: HTML is the standard markup language for creating web pages.
  • Structure & Elements: It describes the structure of a web page using a series of nested elements.
  • Browser Rendering: It tells the browser how to display the content.
  • It labels different pieces of content such as headings, paragraphs and links.

A Simple HTML Document

Example of a basic HTML document:


<!DOCTYPE html>
<html>
    <head>
        <title>Page Title</title>
    </head>

    <body>
        <h1>My First Heading</h1>
        <p>My first paragraph.</p>
    </body>
</html>

Example Explained

  • <!DOCTYPE html>: Defines that this document is an HTML5 document.
  • <html>: It is the root element of an HTML page.
  • <head>: Contains meta information about the HTML page.
  • <title>: Specifies the title of the HTML page. It is shown in the browser's title bar or tab.
  • <body>: Defines the body of the document. It contains all visible contents such as headings, paragraphs, images, links, tables and lists.
  • <h1>: Defines a large heading.
  • <p>: Defines a paragraph.

Web Browsers

Core Purpose

Web browsers read HTML documents and render them correctly across modern browsers such as Chrome, Edge, Firefox and Safari.

Rendering Mechanism

A browser does not display the raw HTML tags themselves. Instead, it interprets them as instructions to arrange and display the page content.

HTML Page Structure

1. Head and Title

The head area contains page metadata. The title element specifies the text shown in the browser's title bar or tab.

2. Body

The body is the visible portion of the document. All content written inside it, such as headings, paragraphs, images and links, appears in the main browser window.

HTML History

  • 1989: Tim Berners-Lee invented WWW.
  • 1991: Tim Berners-Lee invented HTML.
  • 1993: Dave Raggett drafted HTML+.
  • 1995: HTML Working Group defined HTML 2.0.
  • 1997: W3C Recommendation: HTML 3.2.
  • 1999: W3C Recommendation: HTML 4.01.
  • 2000: W3C Recommendation: XHTML 1.0.
  • 2014: W3C Recommendation: HTML5.
