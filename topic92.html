9. CSS Box Model and Positioning

1. Introduction

CSS Box Model and Positioning are important concepts in web designing.

The Box Model explains how space is arranged around HTML elements. CSS Positioning controls where an element appears on a web page.

2. CSS Box Model

Every HTML element is treated as a rectangular box by CSS. The CSS Box Model describes the structure of this box.

The Box Model consists of four main parts:

  • Content
  • Padding
  • Border
  • Margin

3. Parts of the Box Model

A. Content

Content is the innermost part of the box. It contains text, images and other information.

B. Padding

Padding is the space between the content and the border. It creates space inside the border.

C. Border

Border is the line that surrounds the content and padding. It can have different widths, styles and colors.

D. Margin

Margin is the space outside the border. It separates one HTML element from other elements.

Box Model Example:

div {
    width: 250px;
    padding: 20px;
    border: 5px solid blue;
    margin: 20px;
}
Content Area
This is an example of the CSS Box Model.

4. Box Model Structure

The four parts of the Box Model are arranged from inside to outside in the following order:

  1. Content - Text and images are placed here.
  2. Padding - Space around the content.
  3. Border - Surrounds the padding and content.
  4. Margin - Space outside the border.

5. Content-box

By default, CSS uses box-sizing: content-box. In this model, the declared width applies only to the content.

Padding and border are added outside the declared content width. Therefore, the total rendered width becomes larger.

Example:

div {
    box-sizing: content-box;
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}

Width Calculation:

Given:

  • Content width = 300px
  • Left and right padding = 20px each
  • Left and right border = 5px each

Total width = Content + Left padding + Right padding + Left border + Right border 

Total Width = 300 + 20 + 20 + 5 + 5

Total Width = 350px

Therefore, the rendered width is 350px. Margin is added outside this measurement.

6. Border-box

The box-sizing: border-box property makes the declared width include the content, padding and border.

This makes the total width easier to calculate because padding and border are included in the declared width.

Example:

div {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}

In this example, the total width remains 300px. The content area becomes smaller to make room for padding and border.

Common Global Rule:

*, *::before, *::after {
    box-sizing: border-box;
}

7. Difference Between Content-box and Border-box

Content-box Border-box
Width applies only to content. Width includes content, padding and border.
Padding and border increase total width. Padding and border are included in total width.
Default box-sizing value. Useful for predictable layouts.

8. Margin Collapse

In normal block flow, vertical margins of adjacent block elements can collapse into one margin instead of adding together.

This means the space between two block elements may be equal to the larger of their adjoining vertical margins rather than their sum.

9. CSS Positioning

CSS Positioning is used to control the location of HTML elements on a web page.

The position property specifies the positioning method used for an element.

10. Types of CSS Positioning

A. Static Positioning

Static is the default position value of HTML elements. Elements appear in their normal document flow.

Top, right, bottom and left offsets do not apply to statically positioned elements.

Syntax:

div {
    position: static;
}
Static Box

B. Relative Positioning

Relative positioning moves an element from its normal position.

The element remains in the normal document flow and its original space is still reserved.

Syntax:

div {
    position: relative;
    top: 15px;
    left: 35px;
}

Example:

Relative Box

C. Absolute Positioning

Absolute positioning removes an element from the normal document flow.

It uses the nearest positioned ancestor as its containing block. If there is no positioned ancestor, it is positioned relative to the initial containing block.

Syntax:

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 12px;
    right: 12px;
}

Example:

Absolute Box

Here, the parent has position: relative. Therefore, the absolute child is positioned using the parent box as its containing block.

D. Fixed Positioning

Fixed positioning removes an element from the normal document flow and positions it relative to the viewport.

It generally remains in the same place on the screen when the page is scrolled.

Syntax:

div {
    position: fixed;
    top: 10px;
    right: 10px;
}

Example:

.header {
    position: fixed;
    top: 0;
    width: 100%;
}
Fixed positioning example:
A fixed element can stay at the same viewport position while scrolling.

E. Sticky Positioning

Sticky positioning behaves like relative positioning until a specified scrolling threshold is reached. After that, the element sticks within its scrolling container.

Syntax:

div {
    position: sticky;
    top: 0;
}

Example:

Sticky Position Example

When the sticky element reaches its specified position during scrolling, it stays there within its scrolling container.

11. Difference Between Position Values

Position Working
Static Default position in normal document flow.
Relative Moves from its normal position and keeps its original space.
Absolute Leaves normal flow and uses the nearest positioned ancestor.
Fixed Leaves normal flow and is positioned relative to the viewport.
Sticky Acts relative until a scroll threshold, then sticks.

12. Importance of CSS Box Model and Positioning

  • Controls the size of HTML elements.
  • Creates proper spacing between elements.
  • Helps arrange content on web pages.
  • Controls the position of elements.
  • Makes website layouts easier to manage.
  • Helps create organized and attractive designs.
Exam Point: The CSS Box Model consists of content, padding, border and margin. CSS positioning has five main values: static, relative, absolute, fixed and sticky. These properties control the size, spacing and placement of HTML elements.

13. Conclusion

CSS Box Model explains how an element's content, padding, border and margin are arranged. CSS Positioning helps control the location of elements on a web page. Both concepts are important for creating proper web layouts.
