CSS SYNTAX AND SELECTORS

1. Introduction to CSS Syntax

CSS syntax defines how CSS rules are written. A CSS rule consists of a selector and a declaration block.

2. CSS Rule Structure

A CSS rule contains a selector followed by declarations inside curly brackets. Each declaration contains a property and a value.

Example:

p { color: red; font-size: 20px; }

Here, p is the selector, color and font-size are properties, and red and 20px are their values.

3. Types of CSS Selectors

1. Element Selector

Element selector selects HTML elements using their tag names.

Example: p { color: green; }

2. Class Selector

Class selector selects elements using their class attribute. It starts with a dot (.) symbol.

Example: .box { color: blue; }

3. ID Selector

This heading uses ID Selector.

ID selector selects an element using its unique ID. It starts with the hash (#) symbol.

Example: #heading { color: purple; }

4. Universal Selector

Universal selector selects all HTML elements. It is represented by an asterisk (*) symbol.

Example: * { box-sizing: border-box; }

5. Grouping Selector

Grouping selector applies the same CSS style to multiple HTML elements.

Example: h1, h2, p { color: blue; }

6. Descendant Selector

Descendant selector selects elements present inside another element.

Example: div p { color: red; }

7. Child Selector

Child selector selects only the direct child elements of a parent element.

Example: div > p { color: blue; }

8. Pseudo-Class Selector

Pseudo-class selector is used to define a special state of an element.

Example: a:hover { color: red; }

9. Pseudo-Element Selector

Pseudo-element selector is used to style a specific part of an element.

Example: p::first-line { font-weight: bold; }

10. Attribute Selector

Attribute selector selects HTML elements based on their attributes.

Example: input[type="text"] { border: 2px solid blue; }

4. CSS Properties and Values

A property defines what style we want to change, and a value defines how that property should appear.

Example: color: red;

5. CSS Units

CSS uses different units to define sizes and distances.

px - Fixed CSS pixel unit.

em - Relative to the element's font size.

rem - Relative to the root font size.

% - Used for percentage-based sizing.

vw - Relative to viewport width.

vh - Relative to viewport height.

6. CSS Comments

CSS comments are used to explain code. They are not displayed on the webpage.

Example: /* This is a CSS comment */
