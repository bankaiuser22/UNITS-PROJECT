HTML Text Formatting

Introduction

HTML contains several elements for defining text with a special meaning.

Text formatting tags are used to change the appearance or meaning of text on a webpage.

1. Bold Text - <b>

The <b> tag is used to display text in bold. It makes text look darker without adding extra semantic importance.

Example:

<p>This is normal text.</p>
<p><b>This text is bold.</b></p>

This is normal text.

This text is bold.

2. Important Text - <strong>

The <strong> tag defines text with strong importance. Browsers usually display it in bold.

Example:

<p><strong>
This text is important!
</strong></p>

This text is important!

3. Italic Text - <i>

The <i> tag is used to display text in italic. It is commonly used for technical terms, thoughts and words from other languages.

Example:

<p><i>This text is italic.</i></p>

This text is italic.

4. Emphasized Text - <em>

The <em> tag defines emphasized text. Browsers usually display it in italic. Screen readers can give this text verbal emphasis.

Example:

<p><em>
This text is emphasized.
</em></p>

This text is emphasized.

5. Smaller Text - <small>

The <small> tag is used to display smaller text.

Example:

<p>Normal text
<small>Small text</small>
</p>

Normal text Small text

6. Marked Text - <mark>

The <mark> tag is used to highlight important or marked text.

Example:

<p>
This is <mark>highlighted text</mark>.
</p>

This is highlighted text.

7. Deleted Text - <del>

The <del> tag is used to show deleted text. The browser displays a line through the text.

Example:

<p>
Price: <del>500</del> 400
</p>

Price: 500 400

8. Inserted Text - <ins>

The <ins> tag is used to show inserted text. Browsers usually display it with an underline.

Example:

<p>
I like <ins>HTML</ins>.
</p>

I like HTML.

9. Subscript Text - <sub>

The <sub> tag defines subscript text. It appears slightly below the normal text line.

Example:

<p>H<sub>2</sub>O</p>

H2O

10. Superscript Text - <sup>

The <sup> tag defines superscript text. It appears slightly above the normal text line.

Example:

<p>X<sup>2</sup></p>

X2

Conclusion

HTML text formatting elements are used to change the appearance and meaning of text. They help make webpages more readable and clear.
