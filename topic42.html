CSS TEXT, FONTS, BORDERS AND BOX MODEL

1. Typography and Text

CSS typography is used to control the appearance of text on a webpage. It helps to change font style, size, weight and text alignment.

2. CSS Font Properties

A. Font Family

The font-family property is used to specify the typeface of the text.

This text uses Georgia font family.

Example: font-family: Georgia, serif;

B. Font Size

The font-size property is used to change the size of the text.

This text has a font size of 25px.

Example: font-size: 20px;

C. Font Weight

The font-weight property is used to control the thickness of text.

This text is bold.

Example: font-weight: bold;

3. CSS Text Properties

A. Text Align

The text-align property is used to align text horizontally.

This text is aligned in the center.

Values: left, right, center and justify.

B. Text Decoration

The text-decoration property is used to add or remove decorative lines from text.

This text is underlined.

This text has an overline.

This text has a line through it.

C. Text Transform

The text-transform property is used to change the appearance of letters.

This sentence is displayed in uppercase.

Values: uppercase, lowercase and capitalize.

D. Line Height

The line-height property controls the vertical space between lines of text.

CSS makes webpages attractive. It also improves readability. Line height adds space between lines.

5. CSS Box Model

The CSS Box Model describes how every HTML element is displayed as a rectangular box. It consists of four parts: Content, Padding, Border and Margin.

A. Content

Content is the actual text, image or other information present inside an HTML element.

B. Padding

Padding is the space between the content and the border of an element.

C. Border

Border is the line surrounding the padding and content of an element.

D. Margin

Margin is the outer space outside the border. It separates one element from another element.

6. Example of CSS Box Model

Content Box

In content-box, the given width applies only to the content. Padding and border are added to the total width.

Content Box Example

Border Box

In border-box, the given width includes content, padding and border.

Border Box Example

7. Difference Between Content-box and Border-box

Content-box: Total width increases when padding and border are added.

Border-box: Total width remains the same because padding and border are included in the declared width.

8. CSS Box Sizing Property

The box-sizing property controls how the width and height of an element are calculated.

Example: box-sizing: border-box;
