Introduction to XML

Web Technologies | Unit 5

1. What is XML?

XML stands for Extensible Markup Language. It is a text-based markup language used for representing, storing and transporting structured data.

XML allows users to create their own descriptive tags according to their requirements. It describes the meaning of information rather than its visual appearance.

XML is mainly used to store and exchange structured information between different applications and systems.

2. Example of XML

The following example represents a course record using XML elements and an attribute. 

<course code="WT205">
    <title>Web Technologies</title>
    <credits>4</credits>
    <instructor>Dr. Mehta</instructor>
</course>

In this example, course is the main element. Title, credits and instructor are child elements. The code attribute provides additional information.

3. Important Features of XML

1. Extensible

XML allows users to create their own tags according to the type of data.

2. Structured

XML organizes information in a tree structure using parent and child elements.

3. Portable

XML documents can be read and processed by different software on different platforms.

4. Human Readable

XML uses plain text and meaningful tag names, making the information easier to understand.

5. Data-Oriented

XML focuses on describing and carrying data. Another program or stylesheet decides how the data should be displayed.

4. XML vs HTML

XML and HTML are both markup languages, but they have different purposes.

  • XML is used to store and transport data.
  • HTML is used to display web pages.
  • XML allows custom tags.
  • HTML uses predefined tags.
  • XML focuses on the meaning of data.
  • HTML focuses on the presentation of content.

5. Advantages of XML

  • Easy to read and understand.
  • Supports structured data.
  • Allows custom descriptive tags.
  • Helps applications exchange information.
  • Can be processed on different platforms.

6. Conclusion

XML is an important technology used for representing and exchanging structured data. Its extensible nature, readable format and tree structure make it useful in web technologies and software applications.
