TOPIC 5: EVENTS AND BUTTONS

1. Introduction to Events

An event is something that happens in the browser. It can be caused by a user action or by the browser itself.

For example, when a user clicks a button, types something in an input field, submits a form or presses a key, an event occurs.

JavaScript can detect these events and execute a function in response.

Examples of Events:

  • Clicking a button.
  • Typing inside an input field.
  • Submitting a form.
  • Pressing a keyboard key.
  • Loading a web page.

Simple Example:

When the user clicks the button, JavaScript detects the click event and displays an alert message.

Remember:
Event = Something that happens in the browser.
Event handling = Writing code to respond to that event.

2. What is Event Handling?

Event handling is the process of detecting an event and executing a function when that event occurs.

JavaScript uses event listeners to connect events with functions.

How Event Handling Works:

  1. The browser displays an HTML element.
  2. JavaScript selects that element.
  3. JavaScript attaches an event listener to it.
  4. The user performs an action, such as clicking a button.
  5. The browser detects the event.
  6. The attached function executes.

Simple Flow:

     HTML Element
          |
          v
    JavaScript Selects It
          |
          v
    Add Event Listener
          |
          v
      User Action
          |
          v
      Event Occurs
          |
          v
    Function Executes

3. addEventListener() Method

The addEventListener() method is used to attach an event listener to an HTML element. It tells JavaScript which event to listen for and which function to execute when that event occurs.

It is commonly used for handling button clicks, input changes and form submissions.

Syntax:

element.addEventListener("event", function() {

    // Code to execute

});

Explanation:

  • element: The HTML element on which the event is attached.
  • addEventListener(): Attaches an event listener.
  • event: The event name, such as "click".
  • function: The code that runs when the event occurs.

Example:

Explanation:

  1. First, JavaScript selects the button using its ID.
  2. addEventListener() attaches a click event.
  3. When the button is clicked, the function executes.
  4. The alert message displays "Welcome!".
Important:
Using addEventListener() keeps JavaScript behaviour separate from HTML structure. It also allows several event listeners to be attached to an element.

4. Types of Events

JavaScript supports different types of browser events. Each event is used for a particular action.

1. Click Event

The click event occurs when a user activates an element, such as clicking a button. Native buttons also support keyboard activation.

Syntax:

button.addEventListener("click", function() {

    alert("Button clicked!");

});

Example:

When the user clicks the button, the background colour of the page changes.

2. Input Event

The input event occurs whenever a user changes the value of an input field. It is useful for real-time validation and displaying the entered text immediately.

Syntax:

input.addEventListener("input", function() {

    // Code to execute

});

Example:

Whenever the user types or edits the input, the paragraph displays the updated value.

3. Submit Event

The submit event occurs when a form is submitted. It is useful for checking form information before the form is processed.

Syntax:

form.addEventListener("submit", function(event) {

    // Code to execute

});

Example:

When the form is submitted, the event listener runs. preventDefault() stops the browser's normal form submission so JavaScript can handle the event.

4. Keyboard Events

Keyboard events occur when a user interacts with the keyboard. They can be used to detect which key was pressed.

Two common keyboard events are:

  • keydown: Occurs when a key is pressed down.
  • keyup: Occurs when a pressed key is released.

Example:

document.addEventListener("keydown", function(event) {

    console.log("Key pressed:", event.key);

});

When the user presses a key, its value is displayed in the browser console.

5. Page Load Event

The load event occurs when the page and its dependent resources have finished loading.

Example:

window.addEventListener("load", function() {

    console.log("Page fully loaded!");

});

This code displays a message in the console after the page has finished loading.

5. Event Object

When an event occurs, the browser creates an event object. This object contains useful information about the event.

It helps JavaScript understand what happened, which element received the event and other details about the interaction.

Information Provided by the Event Object:

  • Type of event that occurred.
  • Element that received the event.
  • Keyboard key information for keyboard events.
  • Other details related to the event.

Example:

button.addEventListener("click", (event) => {

    console.log("Event type:", event.type);

    console.log("Clicked element:", event.currentTarget);

});

Explanation:

  • event: Contains information about the event.
  • event.type: Gives the event name, such as "click".
  • event.currentTarget: Gives the element whose listener is currently running.

In this example, when the button is clicked, the browser console displays the event type and the button element.

Remember:
The event object provides information about the event and helps JavaScript decide how to respond.

6. Difference Between target and currentTarget

The event object provides two useful properties: target and currentTarget.

event.target

It refers to the actual element where the event originated.

event.currentTarget

It refers to the element on which the currently running event listener is attached.

Example:

If the button is clicked, the event bubbles to the parent element. The target is the button, while the currentTarget is the parent div.

7. Buttons in JavaScript

Buttons are HTML elements used to perform actions when users interact with a web page. JavaScript can attach event listeners to buttons to make them interactive.

HTML Button Syntax:

JavaScript Button Example:

const button = document.getElementById("myButton");

button.addEventListener("click", function() {

    alert("Button clicked successfully!");

});

Common Uses of Buttons:

  • Displaying messages.
  • Changing text.
  • Changing background colours.
  • Increasing or decreasing a counter.
  • Submitting forms.
  • Showing or hiding content.

8. Interactive Example: Counter Button

This example shows how a button click can increase a counter and update the web page.

Click to Fire an Event Listener

Counter Value:

0

JavaScript Code:

let count = 0;

const output = document.getElementById("counter");

const addButton = document.getElementById("addButton");

const resetButton = document.getElementById("resetButton");

addButton.addEventListener("click", function(event) {

    console.log("Activated:", event.currentTarget);

    count += 1;

    output.textContent = count;

});

resetButton.addEventListener("click", function() {

    count = 0;

    output.textContent = count;

});

Explanation:

  1. count stores the current counter value.
  2. JavaScript selects the counter display and both buttons.
  3. The Add One button listens for a click event.
  4. Every click increases count by 1.
  5. textContent updates the displayed counter.
  6. The Reset button sets the counter back to 0.

10. Event Handling and preventDefault()

Some browser events have a default action. For example, submitting a form normally sends the form data and may load another page.

The preventDefault() method stops that default action. It allows JavaScript to handle the event first.

Syntax:

event.preventDefault();

Example:

form.addEventListener("submit", function(event) {

    event.preventDefault();

    alert("Default submission stopped.");

});

In this example, the normal form submission is prevented and the alert message is displayed.
